# 謀略（戰略層的五種）

## 1. 五種計謀

`L0`（名稱、編號、分派、成敗判定）／`[base]`。五支常式：
驅虎吞狼 `0x2c9d8`、遠交近攻 `0x2c32e`、偽書使疑 `0x2ce66`、
策反人民 `0x2d34c`、聯合出兵 `0x2d88c`，分派器在 `0x2c2ee`。
名稱來自原版字串表
（`AA.EXE` `0x4ef5c`：`1.驅虎吞狼 2.遠交近攻\n3.偽書使疑 4.策反人民\n5.聯合出兵\n那一頂:`，
`docs/re/04` §2）：

| 編號 | 名稱 | 效果 |
|---|---|---|
| 1 | 驅虎吞狼 | 挑動目標勢力去攻打第三方 |
| 2 | 遠交近攻 | 與遠方勢力結交 |
| 3 | 偽書使疑 | 降低目標將領的忠心度 |
| 4 | 策反人民 | 五刀一起下（`0x2d6e0`，`L0`）：民眾忠誠、洪水率、土地價值、米、金 |
| 5 | 聯合出兵 | 邀他人一同出兵 |

## 2. 用計的條件

`L2`／`[base]`（說明書 p.24–25）：

- **要先有軍師**。沒拜軍師就不能用計（`ErrNoChief`）。
- **地點只能是軍師或諸侯所在地**。
- 目標必須是**別人的郡**。

## 3. 成敗判定（`L0`、`[base]`）

五種計謀共用一支（`0x2dd66`，回 `0xFFFF` 表示失敗）：

```
我方 ＝ max(我方軍師的謀略, 我方君主的謀略)
我方人望 < 80     → 我方 += (人望 − 80) ÷ 10      ; 只扣不加
使者的魅力 < 70   → 我方 += (魅力 − 70) ÷ 5       ; 只扣不加
對方 ＝ max(對方君主的謀略, 對方軍師的謀略)
我方 > 對方 → 得手
```

「我方」是**軍師所在郡的所屬勢力**（`es:0x30fc` 指的那個郡，
`0x2dd80` 讀它的 offset 30）。

**人望與使者魅力到了 80／70 就封頂**，兩者只會扣分不會加分——
所以主軸是雙方的謀略對決，人望與魅力是拖後腿的因子。
`internal/game/plot.go` 的 `PlotScore` 就是它。

## 4. 費用

⚠ **說明書沒有給平時五種計謀的費用**（只有戰場上的六種有：火攻 600、
水淹 500、誘敵 400、燒糧 300、圍攻 200、陷阱 100，p.32–34）。
remake 照戰場那一組的量級給：驅虎吞狼／聯合出兵 300、遠交近攻 200、
偽書使疑／策反人民 100。**這是 `L3` 的假設**，等對拍量到再換。

## 5. 未解

- **五種計謀的費用**（上面）。
- **驅虎吞狼與聯合出兵的出兵部分**。現在的實作只做到「成功」，
  真的讓第三方出兵還沒接（`internal/game/plot.go` 明說了這件事）。
- **遠交近攻的效果**：外交狀態在資料裡有沒有欄位還沒解。
  諸侯記錄目前解出 offset 0（控制方）、2（君主）、4（AI 等級）、
  6（軍師）、8（人望）、14–18（五種寶物）——外交關係如果有存，
  在剩下的 offset 10–13、19–71 裡。
- **驅虎吞狼／遠交近攻／偽書使疑／聯合出兵的效果常式**還沒逐一讀
  （策反人民的 `0x2d6e0` 已解）。

## 電腦諸侯的計略是破壞，不是交涉（`L0`、`[base]`）

原版的分派表 `0x56f4` 需要**軍師本人在該郡**，目標是**全圖**任何一個
敵郡（不限鄰接），使者取本郡魅力最高的人。成敗比的是
`max(軍師謀略, 君主謀略)` 對上對方的 `max(君主謀略, 軍師謀略)`，
人望不足 80、使者魅力不足 70 各扣分。

**電腦與玩家走同一支效果常式**：`0x2d6e0` 的兩個呼叫端分別在
策反人民（`0x2d6d7`）與電腦的計略（`0x0e8ba`），兩邊都傳
人物 offset 11（魅力）。所以那五刀確定掛在**策反人民**底下
（原本標 `L2`）。

得手之後對目標郡降民眾忠誠、升洪水率、降土地價值、燒米燒錢——
**五項全是破壞**，沒有任何締約的成分。細節在 `docs/mechanics/70-ai` §2.13.7。
