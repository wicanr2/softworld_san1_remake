# 謀略（戰略層的五種）

## 1. 五種計謀

`L0`（名稱與編號）＋`L2`（效果）／`[base]`。名稱來自原版字串表
（`AA.EXE` `0x4ef5c`：`1.驅虎吞狼 2.遠交近攻\n3.偽書使疑 4.策反人民\n5.聯合出兵\n那一頂:`，
`docs/re/04` §2）：

| 編號 | 名稱 | 效果 |
|---|---|---|
| 1 | 驅虎吞狼 | 挑動目標勢力去攻打第三方 |
| 2 | 遠交近攻 | 與遠方勢力結交 |
| 3 | 偽書使疑 | 降低目標將領的忠心度 |
| 4 | 策反人民 | 降低目標郡的金米與民眾忠誠 |
| 5 | 聯合出兵 | 邀他人一同出兵 |

## 2. 用計的條件

`L2`／`[base]`（說明書 p.24–25）：

- **要先有軍師**。沒拜軍師就不能用計（`ErrNoChief`）。
- **地點只能是軍師或諸侯所在地**。
- 目標必須是**別人的郡**。

## 3. 成功率

`L2`／`[base]`，公式是 **remake 的**：

```
分數 = 軍師謀略 × w1 + 使者魅力 × w2 + 君主魅力 × w3 − 對方軍師謀略 × w4
成功率 = clamp(分數 ÷ 100, 0..95)
```

四個權重都在 `internal/game/plot.go`，是 remake 選的。說明書只說軍師與
使者的能力有影響，沒給公式。

## 4. 費用

⚠ **說明書沒有給平時五種計謀的費用**（只有戰場上的六種有：火攻 600、
水淹 500、誘敵 400、燒糧 300、圍攻 200、陷阱 100，p.32–34）。
remake 照戰場那一組的量級給：驅虎吞狼／聯合出兵 300、遠交近攻 200、
偽書使疑／策反人民 100。**這是 `L3` 的假設**，等對拍量到再換。
