# 勝負：統一判定與玉璽

## 1. 統一的條件

`L2`／`[base]`（`internal/game/events.go` 的 `Winner`）：

**擁有全部有主的郡**，而且**手上有玉璽**。

「在遊戲結束前一定要拿到玉璽」（說明書 p.37）。所以佔滿地圖但沒有玉璽
不算贏——remake 的做法是回報「還要再等數月」而不是直接結束。

## 2. 玉璽怎麼來

`L2`／`[base]`：

- 玉璽是五件寶物之一（玉璽／兵書／寶刀／美女／駿馬），
  在**君主的寶庫**裡（`Faction.Treasury`）。
- 冬季各州郡進貢會給寶物（`50-events` §5）。
- **玉璽不能賞賜給部將**（說明書 p.24）——其他四件可以。
- **戰役決勝時，被消滅一方君主的寶物盡歸戰勝方**（說明書 p.35）。
  所以玉璽會隨著滅國轉手。

## 3. 勢力消滅

`L2`／`[base]`：一個勢力的領土歸零就標記為不再存活。
**君主本人被擒或戰死不等於滅亡**——判準是領土。

## 4. 一局跑得完

`L1`／`[base]`（`internal/session` 的全電腦對戰測試）：
劇本 001 全電腦對戰，約五十年（到 242 年前後）收斂到一個勢力，
經濟數字仍然合理（二十年後總人口 2,223,448）。

⚠ **這證明的是 remake 的規則能收斂，不是原版如此。** 原版跑多久統一
還沒量過——那要在 dosgolem 裡讓原版自己跑完一局。

## 5. 未解

- **原版的統一年份分布**。要拿電腦自動示範模式跑原版來量。
- **君主死亡之後的繼承**。說明書提到君主繼承，remake 還沒實作；
  資料裡有沒有繼承順序的欄位也還沒解。
- **劇本差異**：六個劇本（中平六年 189／興平二年 195／建安六年 201／
  建安十三年 208／建安二十年 215／黃初元年 220，`L0`／`AA.EXE` `0x47586`–`0x475ef`）
  除了初始盤面之外有沒有規則差異，還沒查。
