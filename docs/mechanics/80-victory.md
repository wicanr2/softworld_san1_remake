# 勝負：統一判定與玉璽

## 1. 統一的條件

`L2`／`[base]`（`internal/game/events.go` 的 `Winner`）：

**擁有全部有主的郡**，而且**手上有玉璽**。

「在遊戲結束前一定要拿到玉璽」（說明書 p.37）。所以佔滿地圖但沒有玉璽
不算贏——remake 的做法是回報「還要再等數月」而不是直接結束。

## 2. 玉璽怎麼來

`L2`／`[base]`：

- 玉璽是五件寶物之一（玉璽／兵書／寶刀／美女／駿馬），
  在**君主的寶庫**裡（`Faction.Treasury`）。
- 冬季各州郡進貢會給寶物（`50-events` §5）。
- **玉璽不能賞賜給部將**（說明書 p.24）——其他四件可以。
- **戰役決勝時，被消滅一方君主的寶物盡歸戰勝方**（說明書 p.35）。
  所以玉璽會隨著滅國轉手。

## 2.5 君主繼承（`L0`、`[base]`、`0x14a40`–`0x14ce6`）

君主死掉時原版做的事，照順序：

```
死者：身分 ← 12（已故）、勢力 ← 0xFF、領地 ← 0xFF
候選 ＝ 掃全人物表（350 筆），勢力欄等於這一方的人
候選依**魅力**由高到低排序（選擇排序，0x14ad2）
候選是空的 → 「無人繼承」（DS:0x657a），勢力 offset 0 ← 0xFFFF
             手上有玉璽的話一併釋出（offset 14 ← 0）
否則：
    電腦操縱 → 取排頭（魅力最高）
    玩家操縱 → 開清單自己挑（0x14f7c）
    勢力人望 ← 四捨五入(繼承者魅力 × 原人望 ÷ 100)
    繼承者原本是軍師 → 軍師欄 ← 0xFFFF
    諸侯記錄的君主欄 ← 繼承者
    繼承者：職位 ← 0、兵種 ← 6、身分 ← 君主
```

**候選不限於死者所在的郡**——掃的是整張人物表。君主戰死在外地時，
只從同一個郡找會找不到人，而勢力就這樣無聲地滅了。

**魅力就是繼承的代價。** 人望決定部下忠誠每年的漲跌，魅力 100 的世子
保住全部人望，魅力 50 的一上任就折半，整個勢力跟著慢慢離心。
那條乘法在原版是浮點的 `× 0.01` 再 `+ 0.5` 取整（`DS:0xa6f8`／`DS:0xa700`）。

「只有在繼承君主時才會改變等級」（說明書 p.18）講的是這一刻。

remake 這一邊是 `State.SucceedLord`／`SuccessionPrestige`；玩家自己挑
那一段還沒接上介面，目前兩邊都取魅力最高的（登記在案的 remake 差異）。

## 3. 勢力消滅

`L2`／`[base]`：一個勢力的領土歸零就標記為不再存活。
**君主本人被擒或戰死不等於滅亡**——判準是領土。

## 4. 一局跑得完

`L1`／`[base]`（`internal/session` 的全電腦對戰測試）：
劇本 001 全電腦對戰，約五十年（到 242 年前後）收斂到一個勢力，
經濟數字仍然合理（二十年後總人口 2,223,448）。

⚠ **這證明的是 remake 的規則能收斂，不是原版如此。** 原版跑多久統一
還沒量過——那要在 dosgolem 裡讓原版自己跑完一局。
