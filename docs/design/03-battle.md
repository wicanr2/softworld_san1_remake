# 戰役：已經做的與還沒做的

原版的戰役分三階段（說明書 p.26–35）：

```
召集 → 對陣 → 決勝
```

## 1. 這一版做了戰略層的決勝

`internal/game/battle.go`：誰打誰、雙方戰力怎麼算、贏了誰接手、
被擒的將領怎麼處置。

已經照手冊的規則：

- 「由該州郡獨力進犯**鄰郡**」——只能打相鄰的郡
- 「主守軍必須派出所有兵力」——守方自動是全部駐軍
- 「若進攻順利，軍隊將駐進被攻下的州郡」
- 「因任何事故所形成的空白郡均不屬任何諸侯」——傾巢而出會被擋下
- 影響戰力的因素：訓練度、武裝度、兵數（地形與兵種在戰術層）
- 城池與關寨的防禦加成
- 被擒敵將的四種處置；**諸侯被擒只能斬首或釋放**

## 3. 介面是照這個方向留的

`Attack(from, to, attackers, by)` 回 `*BattleResult`。戰術層做出來之後，
換掉的是 `resolve` 內部，**不是呼叫端**：

- `attackers` 已經是「派哪幾位出征」，編隊只是把它再分成五組
- `BattleResult.Captives` 已經是被擒名單，決勝的處置不必改
- `roll` 是決定性的，戰術層接上去之後整場戰役仍然可重現

## 4. 先做戰術層還是先做別的

戰術層要的**地形資料還沒解**（`.OKR` 是點陣但用途未知，
`docs/formats/04` §3）。在那之前做出來的地形只能是我編的，
而地形是戰術層的一半——所以順序是：

1. 解 `.OKR`（或找到郡地理誌的來源）
2. 解原版的移動力與戰力公式
3. 才做戰術層

在那之前，戰略層的決勝讓遊戲**跑得完一局**，這比一個地形是編的
戰術層有用。
