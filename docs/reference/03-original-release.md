# 智冠《三國演義》（1991, DOS）原作背景

同名作品太多，先把辨識條件釘死，後面每一節才有共同的對象。這一份談的是
**智冠科技（Soft-World International）1991 年在 DOS 上發行、由陳則孝設計、
執行檔為 `AA.EXE`／`ASV.EXE` 的《三國演義》**，不是光榮（KOEI）的《三國志》系列，
也不是智冠自己後來的二代、三代與線上版。

證據等級沿用 `CLAUDE.md` §8：`L0` 直接讀自原始資料（外盒、手冊、遊戲檔案、
廣告翻拍上的文字）；`L2` 多處間接證據一致的推論；`L3` 假說。分不清版本或
分不清是哪一款的一律標「存疑」。來源代號見 §8。

## 2. 在台灣自製 PC 遊戲史上的位置

1991 年前後，台灣的個人電腦遊戲市場以代理外國作品為主，自製作品多半規模小。
《三國演義》是少數在題材、篇幅與完成度上直接對上日本大廠作品的本地產品。

- **它是「軟體世界」品牌下的第二部完全中文化戰略遊戲**，前作是《楚漢之爭》。
  這是手冊代序與外盒文案的自述（`L0`, R2）。
- **對照組是光榮的《三國志》系列。** 百科與玩家回憶都把兩者放在同一個競爭敘事裡，
  措辭是「遊戲模仿光榮《三國志》系列」（`L2`, R5）、「一場中日的三國遊戲大戰」
  （`L3`，玩家回憶，R14）。這個對照在 1991 年的封面事件裡具體化了（§6）。
- **銷量說法為 17 萬套**，被描述為台灣電腦遊戲史上銷量最高的作品之一（`L2`, R5；
  該條沒有腳註來源）。玩家回憶寫「大賣了十幾萬套」，量級相符（`L3`, R15）。
  沒有找到智冠的官方數字或當年的新聞稿。
- **PC 喇叭語音是它最常被提起的特徵。** 在沒有音效卡的機器上以喇叭模擬人聲，
  在當時的本地作品裡少見（`L2`, R5）。玩家記得的台詞包括「曹操匹夫，安敢欺吾！」
  「汝多行不義，吾將伐之」「良禽擇木而棲」「天亡我，非吾不能也」
  （`L3`，逐字準確度不可靠，R1、R15）。這些字串可以在遊戲資料裡核對，
  本專案的語音實作記在 `docs/re/09`。
- **通路形式**：4 片 1.2M 磁片、NT$300、附防影印密碼表（`L0`, R2）。
  同一份手冊的封底是 Interplay《魔戒少年》的廣告（`L0`, R2），
  可以看出軟體世界同時經營自製與代理兩條線。

## 3. 製作團隊與陳則孝

手冊列出的名單很短（`L0`, R2）：

| 角色 | 姓名 | 出處 |
|---|---|---|
| 設計人 | 陳則孝 | 手冊 p.1 |
| 文字編輯 | 新亭侯、柯志祥 | 目錄頁 |
| 美工編輯 | 黃文鵬 | 目錄頁 |
| 軟體世界雜誌主編 | 吳海境 | 手冊 p.1 |
| 代序致謝 | 姜慧珍 | 手冊 p.1 |

外盒與手冊都沒有列音樂、程式協力或測試名單，也沒有標示封面繪者（`L0`, R2）。
封面畫作的作者在任何一份資料裡都查不到（§6.5）。

陳則孝的背景只有一條間接線索：智冠自 1990 年起舉辦全國性遊戲製作比賽「金磁片獎」，
共辦五屆，得獎者包括陳則孝等人，多人後來加入智冠（`L2`, R6）。
維基的智冠條目本身完全沒提《三國演義》，所以「陳則孝經由金磁片獎被發掘、
《三國演義》是其成名作」這個常見敘述是把兩份資料接起來的推論（`L2`, R5＋R6）。

**找不到陳則孝本人的訪談、開發紀錄或技術文章。** 這是這次資料蒐集裡最明顯的空白。

## 4. 玩法

以下依原版紙本手冊（`L0`, R2）整理，細節在 `01-manual-10-commands.md` 與
`01-manual-20-mechanics.md`。手冊的規則與數值位階低於執行檔（`CLAUDE.md` §4），
本節只作概觀，不當實作依據。

### 4.1 開局

六個時期擇一，可用君主與初始領地各不相同（`L0`，手冊 p.9–14）：

| # | 年號 | 西曆 |
|---|---|---|
| 1 | 中平六年 | 189 |
| 2 | 興平二年 | 195 |
| 3 | 建安六年 | 201 |
| 4 | 建安十三年 | 208 |
| 5 | 建安二十年 | 215 |
| 6 | 黃初元年 | 220 |

各時期可容納的玩家人數不同，也可以自建新君主。難度以數字設定，
手冊說明「難度 1～2 電腦對手不會主動攻擊」，但沒有印出上限值——
上限是版本差異所在（§5）。

### 4.2 戰略層

地圖由 **42 個郡**組成（手冊只用編號 1–42 稱呼，全書沒有郡名對照表，
郡名要從遊戲資料取得）。**每郡每月可下一次指令**，部分查詢功能不耗用次數。
指令分十類（`L0`，手冊 p.17–26）：

| # | 類別 | 內容 |
|---|---|---|
| 0 | 狀態 | 顯示該地基本資料，不耗指令 |
| 1 | 查看 | 州郡、將軍列表、檢視將軍、領土列表、郡地理誌、君主物品 |
| 2 | 軍事 | 調動軍隊、發動戰役、運送錢糧 |
| 3 | 兵士 | 訓練、徵兵、購買武器、調整兵力 |
| 4 | 內政 | 土地開發、洪水防治、建築關寨、休息 |
| 5 | 商業 | 米糧買賣 |
| 6 | 人事 | 人事任免與登用相關 |
| 7 | 君主 | 君主層級的處置 |
| 8 | 謀略 | 對其他勢力施行的計策 |
| 9 | 其他 | 存檔等雜項 |

數值面的例子（`L0`，手冊）：徵兵每人 1 金且不得使郡內人口低於 3000；
武器每 100 單位 1 金；開墾與防洪各耗 10 金；關寨要求監工將領謀略 ≥ 80、
每郡上限五座、每座造價為當月物價的 100 倍。將領屬性為家世、現職、忠心、年齡、
體能、謀略、戰力、魅力、等級、兵種、兵數、訓練度、武裝度。
手冊附錄三收錄 **342 名獨立立條的人物**。

### 4.3 戰術層

戰役分**召集 → 對陣 → 決勝**三段（`L0`，手冊 p.26–35）。

- **召集**：四種軍力（主攻軍、助攻軍、主守軍、助守軍），各自編成
  中軍、先鋒、左軍、右軍、後軍五組，每組最多 10 名將領；君主參戰時
  其所在隊伍為帥軍，否則以中軍為帥軍；主守軍必須派出全部兵力。
- **對陣**：在戰場上紮營後逐日行動，行動順序固定（主守軍 → 助守軍 → 主攻軍 → 助攻軍，
  組內為先鋒 → 左軍 → 右軍 → 中軍 → 後軍）。主戰場九個指令為休息、移動、對戰、
  快戰、死戰、弓箭、策略、查看、退兵；進入「對戰」後另有休息、行軍、單挑、攻擊、查看。
  策略六種：火攻、水淹、誘敵、陷阱、燒糧、圍攻，各有智力門檻、金錢代價與天候地形條件
  （例如火攻要求智力 ≥ 80、耗 600 金、且限刮風時節）。
- **決勝**：守方撐滿**卅天**且城池未失即算守成；攻方攻下城池並撐到卅天即獲勝。
  被擒的敵將可斬首、囚禁、釋放或招降，被擒的君主只能斬首或釋放。

地形（山丘、樹林、水域、城池、關寨、平原、沙漠）對攻防與計策效果各有修正，
弓箭可射次數由部隊武裝度平均值除以 20 取整。

### 4.4 時間與事件

以月為單位推進，四季各有事件（`L0`，手冊 p.36–37）：春天將領增齡、體能衰退、
體能歸零則死亡，另有新血投效與地震；夏天洪水；秋冬另有對應事件。
天災的敘述與民眾忠誠掛鉤。全局跨度可達百餘年，人物依年代登場與死亡（`L2`, R5）。

## 5. 原版與加強版

### 5.1 隨遊戲附的 README 怎麼說

兩份 bundle 內的 `README.DOC` 是同一個檔案，標題為「三國演義新版新增功能說明」
（`L0`, R3）。它逐條列出：

1. 本版為三國演義增強版，和《軟體世界》雜誌第 28 期所附的程式一樣，`DATA5.GRP`（6 月 27 日）。
2. 新版操作和原手冊略有不同。
3. 密碼只須輸入一次。
4. 語音功能可調整（1–30000），一般 16MHz 的機種約在 100 左右。
5. 遊戲難度由 1–10 增加為 **1–20**；11–20 的差別是「防守方若主帥軍被消滅並不算敗」。
6. 總兵數為 0 者敗。
7. 意見可留信於軟體世界 BBS 高雄站，收信人 `Shou Chen`。

《軟體世界》第 28 期對應 **1991 年 7 月號**（`L2`, R10）。配合 `DATA5.GRP` 的
6 月 27 日日期，加強版最早的散布形式是**隨雜誌附送的單一檔案更新**，
時間落在 1991 年 6 月底至 7 月（`L2`, R3＋R10）。

### 5.2 本專案量到的

`docs/mechanics/90-version-diff.md` 的結果（`L0`／`L1`，R4）：

- **難度提示字串**：原版 `請設定難度(1-10):`，加強版 `請設定難度(1-20):`。
  DGROUP 裡 408／401 條字串中有 400 條相同，這是唯一的字串差異。
- **電腦諸侯的出兵係數表**：原版 11 格、加強版 21 格，加強版的 11–20 與 1–10 逐格相同，
  但 1–10 的值兩版不同（例如難度 10：原版 0.5、加強版 0.6，係數越小越保守）。
- **戰役勝負判定多兩條**：難度 ≥ 11 時跳過「守方統帥全滅 → 攻方勝」；
  另新增「一方總兵數為 0 即判敗」且不看難度。兩條對得上 README 第 5、6 項。
- **劇本資料兩版完全相同**：六個劇本的三張表逐位元組零差異，開局盤面一模一樣。
- **配樂、人物頭像、地圖圖形沒動**（`DATA1/3/4.GRP` 完全相同）。

也就是說，加強版**不是加內容，是改數值與少數判定**。

### 5.3 還不確定的

- 難度 11–20 具體改了哪些規則，除了上述兩條之外還有沒有第三條（`L3`）。
- 網路上沒有任何一份資料說明「加強版加強了什麼」；維基、下載站、百科類全都不提加強版
  （查證結果，R5、R7、R11 均無）。README 是目前唯一的說明。
- 「加強版／增強版／新版」在不同來源是不是同一件事，未確認（存疑）。

## 6. 兩個封面，以及光榮在台代理的廣告

### 6.1 事情本身

《三國演義》有**兩個外盒封面**：先發行的一版，與後來改繪的一版。改版的原因，
按收藏者的說法，是**先發行的那張封面與光榮《三國志》的封面構圖重疊，
被光榮在台代理登廣告拿來作文章**。

一手陳述出自 PTT Old-Games 的貼文〈[閒聊] 智冠三國演義的兩個封面〉
（cloudy1124，2026-08-16，R1），原文為：

> 總算收全雙版本的智冠三國演義了…
> 左側的就是被光榮登廣告酸的封面，後來改版出右側的圖…其實構圖差不多，也是很致敬的XD
> 但就法規層面來說，智冠不改版繼續用，當時也是不違法的XD

貼文附兩張照片：一張是兩盒並排的實物，一張是當年那則廣告的翻拍。
推文另有一條把封面與程式版本對起來（`L3`，網友回憶）：
「左邊舊封面是原始版本，右邊改版後，程式是加強版，電腦難度可以到 20 級」——
「難度 20」這一點與 README 及本專案量到的結果一致（§5），所以這條回憶的可信度不低，
但**封面與程式版本的對應關係本身沒有第二個來源**。

**本專案手上的實體與舊封面一致**（`L0`, R2）：`workplace/manual/珍098-三國演義/000.jpg`
的外盒正面，與照片中的左盒逐項相符——銀色題字牌、牌下「4 片裝 NT 300 元」、
左下角黃框「全部中文顯示」、底線「只適用 AT 以上機種・軟碟需兩台 1.2M 磁碟機」。
這份外盒配的是原版說明書（手冊全書沒有加強版的任何字樣）。

兩張封面的內容（`L0`，依照片描述，不轉錄畫作）：

| | 舊封面 | 新封面 |
|---|---|---|
| 天空 | 藍天 | 夜空，有弦月 |
| 上緣 | 五名戴冕冠的君主頭像橫向並列 | 另一組人物頭像，戴冠與頭巾樣式不同 |
| 中段 | 紅衣人物騎紅馬，持刀 | 紅衣白鬚老將騎紅馬，持刀 |
| 下緣 | 火光、持長兵的武將、藍衣文士 | 城牆與火光、持兵器的武將 |
| 「全部中文顯示」標 | 左下角 | 右上角 |
| 售價標 | 題字牌下方印刷 | 右下角黃色標籤 |

兩盒都印「4 片裝 NT 300 元」與相同的機型說明，屬同一條產品線的前後兩版包裝。

### 6.2 廣告上寫了什麼

照片翻拍的是一則整版平面廣告（`L0`，直接讀自照片上的文字，R1）：

- 左上角是 **ACER 標誌**（宏碁當時的字標與紅黑菱形標）。
- 右上角紅底橫幅：**「KOEI 系列產品——行家篇」**。
- 版面中央左側是光榮《三國志Ⅱ》的日文原裝盒，盒面貼黃色「600」價標，
  側面有中文代理商標籤（字太小，翻拍已無法判讀，存疑）；右側是明顯較小的
  智冠《三國演義》盒，用的是**舊封面**。兩盒之間印一個大大的 **「≠」**。
- 大標：**「考驗玩家的眼光」**。
- 內文：**「如果您是一位真正的行家，您怎麼會讓仿冒品充斥在您的收藏中？
  而不知如何分辨真偽？如果您想成為一位行家，您更應該學習以下列的鑑賞方式，
  練就一雙銳利雙眼來收藏真品。」**

**照片只拍到廣告上半。** 內文說的「以下列的鑑賞方式」那一段條列沒有入鏡，
所以「被指為仿冒品的是智冠那一盒」是從版面推出來的（並列＋「≠」＋大小對比），
不是從文字裡直接讀到的（`L2`）。當年「仿冒品」一詞也常指盜版拷貝，
廣告的訴求同時可以讀成「別把長得像的那一盒當成光榮的產品」——
兩種讀法都指向同一件事：**兩張封面像到需要登廣告區隔**。

### 6.3 廣告的年代

廣告本身沒有印日期，翻拍也沒有刊物版權頁。可以推的邊界（`L2`）：

- 廣告掛 ACER 標誌。宏碁子公司**第三波**與光榮的合作記者會在 **1991 年 10 月 15 日**，
  第三波以此正式進入國內娛樂軟體市場（R11，《電腦玩家》1992 年 8 月第 13 期的
  公司報導，受訪者為第三波主管）。合作**從《三國志2》開始**這一點只見於
  搜尋摘要（R12，原頁 403 未能讀取，存疑）。
- 同一篇報導提到光榮原本要求兩千元以上的售價，經反映後「才勉強同意英文版售價六百元」
  （R11）。廣告上那張「600」價標與這個數字相符。
- 因此廣告**不早於 1991 年 10 月**，也就是在《三國演義》原版上市（1991 年 4 月）
  與加強版隨雜誌散布（1991 年 6–7 月）之後。

由此可以排出一條**尚未證實的順序**（`L3`）：原版（舊封面）→ 加強版程式隨雜誌流通 →
第三波代理光榮並登廣告 → 智冠改繪封面，新封面盒內裝加強版程式。
這條順序與推文的說法相容，但**沒有直接證據**；改封面的實際時間點未知。

刊登的刊物也未知。智冠自家的《軟體世界》不太可能刊登這則廣告；
《電腦玩家》創刊於 1991 年 8 月前後（由第 13 期＝1992 年 8 月回推，`L2`），
時間上對得起來，是值得優先翻查的方向，但這只是推測。

### 6.4 與《三國志Ⅱ》封面的構圖比對

拿光榮《三國志Ⅱ》的封面（R13）與舊封面對照，兩者的版面骨架相同（`L2`，
以低解析度圖片目視比對，非畫作鑑定）：

| 元素 | 《三國志Ⅱ》 | 《三國演義》舊封面 |
|---|---|---|
| 上緣 | 一列戴冕冠的君主頭像，由左後往右前排開 | 同樣一列戴冕冠的君主頭像，排法相同 |
| 中段 | 騎馬武將與持兵器人物交疊 | 騎紅馬的紅衣武將與持長兵武將交疊 |
| 下緣 | 橘紅火光，前景有單獨人物 | 橘紅火光，前景有藍衣文士 |
| 色調 | 上藍下橘紅 | 上藍下橘紅 |

人物臉孔、姿勢與細節不同，不是同一張畫；相似的是**構圖公式與配色分層**。
這與貼文作者「其實構圖差不多」的描述一致（R1）。

《三國志Ⅱ》的封面插畫作者，一般說法是長期為光榮繪製《三國志》系列插畫的
**生賴範義**（`L2`，搜尋結果的概述，未取得指名《三國志Ⅱ》封面的一手出處，存疑）。
智冠這一版封面的繪者不明（§6.5）。

### 6.5 可信度與沒查到的部分

**可信度評估**：

| 斷言 | 等級 | 依據 |
|---|---|---|

| 舊封面與光榮《三國志Ⅱ》構圖高度相似 | `L2` | 目視比對（R1、R13）|

**沒查到的**（查過的方向列在下面，都落空）：

- 這則廣告刊登在哪一本雜誌、哪一期、哪一年月。
- 光榮或其代理商當年是否有法律動作。**沒有任何資料顯示曾有訴訟或正式警告**；
  貼文作者的看法是「就法規層面來說，智冠不改版繼續用，當時也是不違法的」（R1），
  這是網友意見，不是法律事實。
- 智冠對此事的任何公開回應。
- 兩張封面的繪者姓名（手冊與外盒都沒有標示，`L0`, R2）。
- 除了 R1 之外，**沒有第二個獨立來源提到這件事**。維基、百科類、下載站、
  攻略站、玩家部落格全都不提封面（R5、R7、R8、R11 等）。

**查過的關鍵字與站台**（全部無所獲，除 R1 外）：
「智冠 三國演義 封面 重疊／爭議／抄襲／雷同／撞圖」、
「光榮 登廣告 智冠 封面」、「考驗玩家的眼光」（廣告大標）、
「行家篇」、「智冠 遊戲 封面 盜用 日本 插畫」、

站台方面查過維基百科、百度百科鏡像、青衫之友、Xuite 舊文、巴哈姆特

照片本身是強證據（廣告的版面、字體、用語都與 1990 年代初的平面廣告相符），
但**單一來源就是單一來源**；要抬到 `L0`，需要找到那則廣告的刊物出處，
或第二份獨立的當年資料。

搜尋時最容易混進來的是光榮《三國志》系列、央視電視劇，以及智冠後續各代。
下載站與百科的條目常把幾代的敘述混在一起；`02-web-30-sources.md` 對每個來源
逐一標了「講的是哪一版」，引用前先查那份。

另外要注意**同一款的兩個版本**也會被混談：`02-web-*` 的多數敘述沒有區分原版與加強版，
而兩版的執行檔、`DATA0`／`DATA2`／`DATA5` 內容都不同（§5）。

## 9. 待追

1. **那則廣告的刊物出處。** 優先方向是 1991 年底至 1992 年的《電腦玩家》與第三波自家刊物；
   《軟體世界》是智冠自家雜誌，可能性低。
2. **《軟體世界》第 28 期（1991 年 7 月號）**。README 說加強版程式隨該期附送，
   該期可能有加強版的官方說明。Internet Archive 有《軟體世界》合集
   （`https://archive.org/details/soft-world-magazine-collection`），尚未成功列出檔案清單。
3. **新封面盒的實物**。能取得的話，可以驗證「新封面＝加強版程式」這條推論，
   並比對外盒文案是否提到難度 20。
4. **陳則孝的訪談或當年報導**。目前完全空白。
5. **封面繪者**。外盒與手冊都沒有標示。
