# 《三國演義》(智冠 1991) 遊戲機制

## 1. 開局流程

啟動後依序是：片頭畫面（可按 `Esc` 跳過）→ 遊戲設定選單 → 選時期 → 選玩家人數 → 選角色 → 選難易度 →（若選新君主則做七項設定）→ 輸入密碼 → 主畫面。（p.7、p.14、p.15）

### 玩家人數與難易度（p.14）

- 「首先請輸入玩者人數，**鍵入 0 表示由電腦進行示範**。」
- 「然後根據玩者人數分別挑選自己所欲扮演的諸侯角色。」
- 「接下來請鍵入遊戲難易度，**難度 1～2 乃為玩者提供練習，電腦對手將不會主動攻擊**。欲進行電腦示範，最好選擇**難度 3 以上**。」
- 手冊未寫出難度的上限值。
- 各時期可容許的最多人數不同（p.7），手冊未逐一列出人數上限，`[推測]` 等於該時期表中的列數。

### 新君主設定（p.14）

七項設定，順序為：

| 順 | 項目 |
|---|---|
| 1 | 年齡 |
| 2 | 體能 |
| 3 | 謀略 |
| 4 | 戰力 |
| 5 | 魅力 |
| 6 | 領地 |
| 7 | 修改姓名 |

- 「每位新加主有 **100 點基數**，修改二、三、四、五項均需使用點數。」（即體能、謀略、戰力、魅力共用 100 點）
- 「領地也只有**一郡**，而且**必須是空白郡**。」
- 修改姓名以繪圖方式進行（操作見 commands 的「命名」鍵位）。
- 「將點數分配完後，**輸入 0 進行下面的步驟**。」

### 密碼保護（p.15–16）

進入主遊戲畫面前需比對隨附密碼表：先比照畫面找出相同**首圖**，再從該頁找出對應畫面的**橫圖**，並配合**地支**找出交叉所在的密碼；鍵入後按 `Enter`，再按 `Y` 確認。手冊範例：地支為「申」，密碼為 `2492`。

## 3. 主畫面（p.16–17）

版面分三區：

| 區域 | 位置 | 內容 |
|---|---|---|
| 進行時間 | 畫面左邊 | 遊戲中的年代時間 |
| 地圖 | 中間 | 單色時以不同紋飾、彩色時以不同顏色區分各諸侯勢力；下令和動作中的州郡號碼另有標示 |
| 訊息欄 | 右方上半 | 州名郡稱和編號、所屬諸侯姓名及其威望，及該地治理狀態 |
| 指令欄 | 右方下半 | 十類指令 |

訊息欄的圖片為當地太守肖像，圖下是太守姓名；**金**代表該地庫銀數量，**米**代表該地糧倉存量；**現役將**為含太守在內的地方文武官員數量，**在野武將**指尚未出仕的當地人才，**兵士**則為所有現役將麾下的兵力總合。（p.17）

「諸侯所在地之外的領土**必須指派太守治理**。」（p.17）

| 屬性 | 手冊說明的作用 | 出處 |
|---|---|---|

| 名稱（州名郡稱） | — | p.16、p.19 |
| 太守姓名 | — | p.19 |

| 糧倉存量（米） | 上限 30000 單位 | p.17、p.19、p.22 |
| 現役駐地將領人數 | 含太守在內的地方文武官員 | p.17、p.19 |
| 全郡總兵力 | 所有現役將麾下的兵力總合 | p.17、p.19 |

**郡地理誌**：可觀看該郡地形圖，「圖中的數字位置代表前往鄰近州郡的通道，也是鄰郡攻入時的發兵地點。」（p.19）

**空白郡**：因任何事故所形成的空白郡均不屬任何諸侯（p.19）。新君主的起始領地必須是空白郡（p.14）。

## 5. 將領屬性

「檢視將軍」的完整欄位（p.18–19）：姓名、肖像、家世、現職、忠心、年齡、體能、謀略、戰力、魅力、等級、兵種、兵數、訓練度、武裝度。

| 屬性 | 手冊說明的作用 | 出處 |
|---|---|---|
| 忠心（忠誠度） | 高者不易叛逃；**叛將會帶走麾下的軍隊**；可藉賜金或贈物提升 | p.18 |
| 年齡 | 越大體能越差 | p.18 |
| 體能 | 降到 0 便告死亡；在天災人禍頻繁的地方久居，壽命比較容易受影響；戰場上單打獨鬥也相當重要 | p.18 |
| 謀略 | 高者較不易中計，用計的成功率也較高 | p.18 |
| 戰力 | 越強在戰場上表現越好，**特別是在單打獨鬥時，相差一點就足以決定生死** | p.18 |
| 魅力 | 對地方行政有相當的影響，政命施行較無阻礙 | p.18 |
| 等級 | 影響麾下軍隊最大值；**只有在繼承君主時才會改變等級** | p.18 |
| 兵種 | 和作戰效果有關 | p.18 |
| 兵數（兵士） | 現在率領的兵員數量 | p.18 |
| 訓練度 | 以百分表示，與作戰效果有關；也影響移動力 | p.18、p.29 |
| 武裝度 | 以百分表示，與作戰效果有關；決定弓箭可射次數 | p.18、p.32 |

**軍師**：「軍師級代表此文官是拜為軍師的最佳人選，受封軍師的人才是真正向諸侯諫言獻策的重臣。」受封軍師者謀略不得低於 80，同時只能有一位，君主不得兼任。（p.18、p.23）

**身分名詞**：「諸侯為君主，治理地方的將領為太守，受封的軍師同時只能有一位。」（p.18）

### 官階與帶兵上限（p.18）

## 7. 回合與時間

- 每郡每月可使用一次指令；部分功能不耗用指令次數（p.17）；附錄一以 `＊` 標出「使用後即轉移控制權」的指令（p.42）。
- 時間以年號表示，可切換西曆／中曆，預設中曆（p.26）。
- 戰役中：「主戰場**每一回合要耗去一天的時間**，而且只有查看指令不限制次數。」（p.28）

## 8. 戰役（馳戰沙場，p.26–35）

每場戰役分三個階段：**召集 → 對陣 → 決勝**。

### A. 召集（p.26–27）

四種軍力：

| 軍力 | 定義 |
|---|---|
| 主攻軍 | 發動戰爭的軍隊 |
| 助攻軍 | 必須運用謀略才能得到，不是本國就是第三國 |
| 主守軍 | 戰場所在州郡的當地駐軍 |
| 助守軍 | 要在應付「聯合出兵」時才會出動 |

編隊：正式作戰前各軍先整編戰鬥隊伍，**順序為主攻軍 → 助攻軍 → 主守軍 → 助守軍**。

戰鬥隊伍分五種：**中軍、左軍、右軍、後軍、先鋒**。

- 如果派出全部兵力，各戰鬥組的將領人數必須平均分配。
- **每組最多 10 名將領。**
- 若諸侯參戰則以諸侯所在隊伍為**帥軍**，否則以**中軍**為帥軍。
- **主守軍必須派出所有兵力**；其他則於調配妥當後按 `Enter` 進行後續動作。

編隊畫面元素（p.27）：兵力、帶隊將領、可用之將領、分配指令。

### B. 對陣（p.28）

- 佈置全軍依**主攻軍 → 助攻軍 → 助守軍 → 主守軍**的順序施行。
- 依**中軍 → 先鋒 → 左軍 → 右軍 → 後軍**的順序紮營在較亮的方格內（單色模式請認清閃爍的方格）。
- 作戰時依**主守軍 → 助守軍 → 主攻軍 → 助攻軍**的順序，並按**先鋒 → 左軍 → 右軍 → 中軍 → 後軍**順序行動。

戰場畫面元素（p.28）：戰場、郡名編號、天氣、作戰時間、主攻軍、主守軍、命令區、時間。

主戰場九個指令與對戰子指令見 `01-manual-10-commands.md`。

### C. 決勝（p.35）

被擒敵將的四種處置：

| 處置 | 結果 |
|---|---|
| 斬首 | 即處死刑 |
| 囚禁 | 成為戰場所在郡的在野將領 |
| 釋放 | 其人將逃至鄰郡 |
| 招降 | 成功便立刻成為部下 |

「**諸侯被擒只能將其斬首或釋放。**」

勝負條件：

- **守方**：能堅持抗戰滿**卅天**，且城池未被奪去就算衛郡成功；或主攻軍及助攻軍全滅或全撤退；若主攻軍或助攻軍的君主死亡，攻方必須全部撤退。守軍只要統帥未出事仍可繼續奮戰。
- **攻方**：攻下城池並堅持到**卅天**為止就算獲勝。若主攻軍全滅或因故撤退，助攻軍尚可繼續進攻。守軍的統帥被俘的話，守軍必須撤兵。**只有在主攻軍全滅或撤退後，助攻軍才能攻佔該郡。**
- 助攻軍在主攻軍獲勝後，或助守軍在助攻軍獲勝後都然安返原郡駐守。
- 獲勝軍若於戰後捉到敵軍君主，**其寶物將全歸獲勝軍所有**。
- 「另外要注意有些不忠之人可能在陣前反叛。」

## 9. 特殊事件（p.36–37）

「在四季中各有特定事件發生，尤其**天災多因人怨引起，民眾忠誠最好不要太低**。」

### 春天

| 事件 | 效果 |
|---|---|
| 年齡增加 | 每位將領年齡都會慢慢增長，其體能也隨之逐漸減退 |
| 將領老死 | 當體能逐年降到 0 時，此將便告死亡 |
| 新血出現 | 新將投效其親族朋友 |
| 地震 | 強烈地震將造成郡內的人口減少，財物和米糧的損失，及部隊兵力傷亡 |

### 夏天

| 事件 | 效果 |
|---|---|
| 洪水 | 造成郡內**洪水率激升 100**，人口和兵力都會減少，土地價值也會流失 |
| 瘟疫 | 除了人口和兵力銳減之外，將領的體能也因而不正常地下降 |

### 秋天

| 事件 | 效果 |
|---|---|
| 收成 | 秋收過後土地價值會略降，稅金入庫、米糧進倉 |
| 蝗害 | 導致歉收，除了米糧減少外，土地價值也會下降 |

### 冬季

| 事件 | 效果 |
|---|---|
| 人口增加 | 人口是兵力的主要來源，**郡內人口少於 3000 人就無法徵兵** |
| 進貢物品 | 各州郡每年進貢寶物給諸侯，**領地越多，貢品越多** |

## 10. 勝利條件（p.37）

「E、一統天下：在遊戲結束前**一定要拿到玉璽**，如果屆時玉璽尚未到手，便須再多等候數月才能看到君臨天下的結局。」

相關：玉璽只能諸侯持有，不能送人；玉璽持有人將會聲名大噪（p.24）。

## 11. 手冊提到但未給規則細節的項目

以下在手冊中被點名，但沒有給出數值或判定式，remake 需另找來源（反組譯或實測）：

- 難易度的上限值、各難度的具體差異（除「1～2 電腦不主動攻擊」外）。（p.14）
- 各時期可容許的最多玩家人數。（p.7）
- 「威望／人望」的數值範圍與計算式；只知其影響招人、用計和收成。（p.16）
- 五種計謀（驅虎吞狼、遠交近攻、偽書使疑、策反人民、聯合出兵）的成功率公式與費用。（p.25）
- 兵種與地形的具體加成倍率。（p.18）
- 等級與官階的晉升規則（只寫「繼承君主時才會改變等級」）。（p.18）
- 天氣（刮風、下雨）的產生機率。（p.28、p.32、p.33）
- 「地板」這個地形在對戰畫面的定義。（p.30、p.31）
