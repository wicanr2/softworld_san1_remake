## 18. 手冊未定義而 remake 仍需命名的項目

- **42 個郡的名稱**：手冊只以編號 1–42 稱呼州郡，全書未列出任何一個郡名對照表（p.9–13、p.42）。郡名必須另從遊戲程式或畫面取得。
- **五首樂曲的曲名**：p.7 只說「五首樂曲」。
- **官階的晉升名稱順序**：p.18 只給五組官階與兵力上限，未說明晉升關係。
- **難易度的名稱**：p.14 只有數字，無稱謂。
