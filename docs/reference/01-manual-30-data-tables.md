## 10. 弓箭次數公式（p.32）

```
可射次數 = ⌊ (部隊各單位武裝度的平均值) ÷ 20 ⌋
```

手冊範例：`(75 + 80 + 50 + 100) ÷ 4 = 76.25` → `76.25 ÷ 20 = 3.8125` → 共能射 **3** 次箭。
