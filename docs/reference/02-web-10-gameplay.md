## 0. 這一份資料的版本歸屬

本文絕大部分內容出自 **S04（青衫之友交流網 `as.htm`）**，該頁自述「本版為加強版」，
攻略部分署名作者「青衫」。因此下列指令表、屬性表、事件表、數值表**預設對應加強版**，
與原版的差異未經對照。少數條目出自 **S07（Xuite 部落格）**，該文提到正版需用 5.25 吋
磁片當遊戲碟，較可能在描述原版，但無法確定作者實際玩的是哪一份。

S04 是玩家整理的攻略，不是官方手冊。內容內部一致、具體到郡編號與數值，
品質明顯高於其他來源，但**仍然沒有任何一條被獨立來源印證過**。

## 1. 開局流程（S04）

1. 選擇時期（六選一）。
2. 選擇玩家人數，`0` 表示由電腦示範。
3. 選擇各玩家要玩的君主，也可以是新君主（每個時期可選的新君主數目不定）。
4. 設定難度 1～10。難度 1～2 為練習用，電腦操控的對手不會主動攻擊；若由電腦示範，
   建議選難度 3 以上。
   - 這是**原版**的上限。加強版是 1～20（提示字串與係數表都量過，`L0`，
     見 `docs/spec/004`）；S04 這一段對應原版。
5. 若選新君主，可調整屬性，但有 **100 點配額**限制：

| 屬性 | 預設 | 可調範圍 | 是否耗點數 |
|---|---|---|---|
| 年齡 | 18 | 8～72 | 否 |
| 體能 | 80 | 50～95 | 是 |
| 謀略 | 50 | 5～90 | 是 |
| 戰力 | 50 | 5～90 | 是 |
| 魅力 | 50 | 40～90 | 是 |
| 人望 | 80 | 不可變更 | — |
| 領地 | — | 任選一個空白郡 | — |

新君主的名字必須用點陣繪圖方式自造，操作鍵：`0` 畫點／清點、`C` 清除一個字、
`R` 讀取現有的字（`Space` 下一頁、`Enter` 上一頁）、`S` 儲存。

翻頁鍵為 `Space`。S07 補充：大部分選擇用數字鍵盤完成。

## 3. 州郡（S04）

全遊戲共 **42 郡**。這個數字是本次研究中少數有旁證的：S04 另一段給的資料表位址，
換算後州郡區塊長度恰好是 `42 × 176 = 7392` byte，與此處的郡數、
與該頁宣稱的郡結構長度三者一致（推導見 `02-web-20-technical.md` §2.3）。

每郡的屬性：

| 屬性 | 說明 |
|---|---|
| 土地價值 | 影響秋收與人口增長；洪水、蝗害會減少；秋收後亦略降 |
| 洪水率 | 影響洪水發生率與人口增長；發生洪水時直接升至 100；每年各地洪水率會上升 |
| 物價 | 影響買賣價格 |
| 民眾忠誠 | 影響天災發生率；可用「開倉賑民」提升 |
| 人口 | 影響徵兵數；洪水、地震、瘟疫會減少；每年冬季增加 |
| 金 | 上限 30000；地震減少，秋收增加 |
| 糧 | 上限 30000；地震減少，秋收增加 |
| 現役將 | 文武官員數量 |
| 在野武將 | 尚未出仕的人才數 |
| 兵士 | 現役將兵士總和 |

君主所在地以外的州郡必須指派太守治理。

## 4. 武將屬性（S04，S07 佐證）

| 屬性 | 效果 |
|---|---|
| 職位 | 君主、太守、軍師、部將 |
| 忠心度 | 太低可能叛逃；可用賞賜金帛或賞賜物品提升 |
| 年齡 | 愈大體能愈差；太老可能過世 |
| 體能 | 隨年齡老邁或瘟疫減少；降到 0 即死亡；影響單挑結果（S07 說單挑時可視為 HP） |
| 謀略 | 影響中計機率與用計成功率 |
| 戰力 | 影響作戰效果與單挑結果 |
| 魅力 | 影響行政效果、運送錢糧的耗損 |
| 等級 | 影響士兵數最大值；只有繼承為君主或受封為軍師時才會改變 |
| 兵士數 | 目前率領的兵員數量；洪水、地震、瘟疫會減少 |
| 訓練度 | 上限 100%；影響作戰效果；行軍移動力隨之上升 |
| 武裝度 | 上限 100%；影響作戰效果與射箭次數；行軍移動力隨之些微下降 |
| 兵種 | 影響各種戰場地形的作戰效果 |
| 人望 | （君主屬性）影響招降登用、謀略用計、秋收效果 |

### 等級對應帶兵上限（S04；S07 完全相同）

| 等級 | 兵數上限 |
|---|---|
| 君主 | 5000 |
| 軍師、大將 | 3000 |
| 參軍、副將 | 2500 |
| 主簿、裨將 | 2000 |
| 謀士、牙將 | 1500 |

文官序列（軍師／參軍／主簿／謀士）與武官序列（大將／副將／裨將／牙將）兩兩同階。

### 兵種（S04）

| 兵種 | 說明 |
|---|---|
| 強力軍 | 萬能兵種 |
| 山 | 適合山丘作戰 |
| 陸 | 適合平地作戰 |
| 水 | 適合水域作戰 |

S04 的資料結構分析另外列出組合兵種的編碼：`00=陸`、`01=山`、`02=水`、`03=山陸`、
`04=水陸`、`05=山水`、`06=強力`（見 `02-web-20-technical.md`）。

### 屬性上限的個案（S07）

- 謀略 100：只有諸葛亮。
- 戰力 100：只有呂布。
- 魅力 100：只有劉備。

這三條與 S04 的武將數值表一致（見第 9 節），算是兩個來源互相印證。

## 5. 時間與事件（S04）

- 每郡每個月可下一次治理命令。
- 1～3 月春、4～6 月夏、7～9 月秋、10～12 月冬。

| 月份 | 可能事件 |
|---|---|
| 1 月 | 將領因年老死去或減少體能。君主死亡則軍師自動繼任，否則由太守或魅力最高的部將繼任。／新將領投效親族所屬君主。／地震：人口、兵士、金銀、米糧減少 |
| 4 月 | 洪水：人口、兵士、土地價值減少，洪水率升至 100。／瘟疫：人口、兵士、將領體能減少 |
| 7 月 | 秋收：獲得稅金與米糧，數量視土地價值、君主人望、人口數、民眾忠誠而定；秋收後土地價值略降。／蝗害：稅金與米糧減少，土地價值下降 |
| 10 月 | 人口增加：視土地價值、洪水率而定。／進貢寶物：領地愈多貢品愈多，每項寶物最多 100 個 |
| 不定 | 獲得玉璽：大幅提升人望 |

## 6. 指令表（S04）

S04 的分類是 0～9 十個群組。S11 說「將戰略決策分為九種，覆蓋軍事、商業、人士、謀略、
內政等」——數量與 S04 的實際群組數（扣掉「0 狀態」與「9 其他」則為 7 類，含這兩項則
為 10 類）**對不上**，S11 的「九種」來源不明。

### 0. 狀態
顯示所在州郡的基本資料。

### 1. 查看
- 選擇州郡（查看領土以外的州郡會耗去一回合）
- 將軍列表（顯示該郡文武官員資料）
- 檢視將軍
- 領土列表（顯示君主所有領土資料）
- 邵地理誌（顯示該郡地形圖，其中數字代表通往的鄰郡，也是鄰郡攻入的位置）
- 君主物品（查看自己可賞賜給下屬的寶物數量；無法查看別的君主）

> 「邵地理誌」照抄 S04 原文。是否為「郡地理誌」的誤植，未確認。

### 2. 軍事
- 調動軍隊：調動將領、金銀、米糧到鄰郡。調入空白郡即立即佔領；調出後原郡若已無將領則成空白郡
- 發動戰役：由該郡獨力進攻鄰郡
- 運送錢糧：運送金銀、米糧到己方其他郡；太守魅力愈高耗損愈少

### 3. 兵士
- 訓練兵士：提升訓練度；將領能力影響提升速度
- 徵兵：每人 1 金，人口減少，人口必須 ≥ 3000
- 購買武器：每 100 單位 1 金，提升武裝度
- 調整兵力：重新編制各將領的兵士數

### 4. 內政
- 土地開發：10 金，提升土地價值；將領謀略愈高效果愈好
- 洪水防治：10 金，降低洪水率；將領謀略愈高效果愈好
- 建築關寨：費用為「當月物價 × 100」金；將領謀略須 ≥ 80；最多 5 個關寨；地點不可在水上，也不可在鄰郡通路上
- 休息

### 5. 商業
- 買入米糧
- 賣出米糧
- 開倉賑民：提升民眾忠誠；太守魅力愈高效果愈好

### 6. 人事
- 尋訪人才：5 金，找尋尚未出現的人才；將領謀略愈高成功機率愈大（除非該郡已無人才）
- 登用人才：30 金，招用在野將領；太守魅力愈高、君主人望愈高，成功機率愈大
- 賞賜金帛：提升忠心度；每月每位將領一次，最高 100 金
- 撤職：免去官員成為在野將領，每位 10 金

### 7. 君主（只有君主所在郡可用）
- 指定軍師：軍師謀略須 ≥ 80，只能一位，可更換，君主不得兼任
- 指定太守：指定非君主所在郡的統治者，魅力高者較能勝任
- 郡縣自治：正常（君主直接下令）／內政（太守自治，內政優先）／軍事（太守自治，軍事優先）／自治（方向由太守決定）
- 賞賜物品：提升忠心度與能力，**能力最多提升到 90**；每月每位將領（含君主）一次；每項寶物最多 100 個
- 登用他國人才：100 金；對象須為其他諸侯的現役將領；若太守被登用則全郡領地與將領皆歸降；君主人望愈高、對方忠心度愈低，成功機會愈大

#### 寶物效果（S04；S07 完全相同）

| 寶物 | 效果 |
|---|---|
| 兵書 | 謀略 +2 |
| 寶刀 | 戰力 +3 |
| 美女 | 魅力 +5 |
| 駿馬 | 戰力 +2、魅力 +3 |

S07 補充：效果可累積，上限同為 90。另外 **玉璽只能諸侯持有、不能送人**，
S07 說拿到玉璽人望變 **100**，S04 只說「大幅提升人望」——**兩者不完全一致，待驗**。
S04 的資料結構分析顯示玉璽在諸侯資料中是 1 byte 的 01/00 旗標，且「遊戲中不能有兩個」。

### 8. 謀略（有軍師之後，軍師與君主所在郡皆可使用）
成功率視我方君主人望、軍師謀略、使者魅力、以及對方軍師謀略而定。

| 計策 | 效果 |
|---|---|
| 驅虎吞狼 | 教唆某郡發兵攻打他郡 |
| 遠交近攻 | 計誘他郡與我方聯合攻打鄰郡 |
| 偽書使疑 | 降低某郡將領忠誠 |

## 7. 戰役系統（S04）

錢糧要帶夠：沒有錢無法用計，也無法查看敵軍資料；米糧不夠則士兵逐日減少。

### 軍別

| 軍別 | 說明 | 顏色（S07） |
|---|---|---|
| 主攻軍 | 發動戰役的軍隊 | 紅 |
| 助攻軍 | 聯合出兵或遠交近攻時出現的友軍 | 紫 |
| 主守軍 | 駐守當地的軍隊 | 綠 |
| 助守軍 | 聯合出兵時對方派出的援軍 | 水藍 |

### 編制

戰鬥編制分為 **中軍、先鋒、左軍、右軍、後軍** 五種，出征將領必須平均分配到這五種編制，
每軍最多 10 位將領（守軍可全部派出），第一位將領為領隊。太守或君主所在部隊為帥軍，
否則以中軍為帥軍。

作戰依 **主守軍 → 助守軍 → 主攻軍 → 助攻軍** 的順序，並按
**先鋒 → 左軍 → 右軍 → 中軍 → 後軍** 的次序行動。每回合耗去一天時間。

S07 對五軍分配的評語是「分這個沒有什麼意義就是了」，與 S04 攻略提示中
「攻方先鋒要強、中軍要少，守方則中軍要強」**互相矛盾**。

### 勝利條件

**守方勝利**：
1. 30 天內未被奪去城池
2. 主攻軍／助攻軍全滅或全撤退

**攻方勝利**：
1. 奪下城池並堅持至 30 天
2. 主守軍統帥被捉

> 加強版 README（專案內檔案）補充：難度 11～20 時「防守方若主帥軍被消滅並不算敗」，
> 且「總兵數為 0 者敗」。這與 S04 列的條件不同，S04 那份大概是原版規則。

## 8. 攻略提示中隱含的機制（S04）

這些是攻略作者的經驗談，不是規則書；但其中幾條隱含了可驗證的機制斷言：

- **人望變動**：人望隨人民忠誠度與領地數改變，佔領空白郡可提升人望；
  **作戰勝利人望 +2，失敗 −2**。傳國玉璽「據說是在袁術手上（不太一定）」。
- **謀略成功門檻**：「人望 90 以上，用計必成。」
- **單挑判定**：**戰力相差 5 點以上才能分出高下**。戰力 80 以上的武將多會答應單挑，
  70 以下多會拒絕。先攻擊一次再要求單挑，答應率較高。
- **洪水防治**只需降到 50 以內即可。
- **建築關塞**既昂貴又無多少用處。
- **徵兵**會降低人口並減少稅收，最好到空白郡徵兵；徵兵後要用「調整兵力」重組新舊兵以平衡訓練度。
- **調動軍隊運送錢糧無耗損**，而「運送錢糧」指令中途會有耗損。
- **賞賜金帛效率低**，寶物才是提升忠心度的主力。

### 兩個被明確描述的漏洞（S04 稱「密技」）

1. **超級徵兵法**：作戰時抓到敵將一律囚禁不招降，戰後將郡縣自治改為「軍事」，
   一兩個月後所有囚禁的敵將都會變成現役將領，兵士數、訓練度、武裝度都是原現役將領的
   平均值，且完全不影響郡縣人口數。
2. **君主捉拿法**：先把對方領地打到只剩一塊且無空白鄰郡，用「聯合出兵」攻打；
   主攻軍的郡縣要有人留守，助攻軍全數出動使該郡暫成空白郡；捉到敵方君主後釋放，
   他會逃到助攻軍所在的郡縣，戰後助攻軍回去時該君主就成為己方將領。
   使用該君主要注意：不可獨自一人當太守（否則自行復國）、出征時不可當主帥
   （否則帶著所有將領一起叛變）。

這兩條對 remake 很重要：它們指出了原版狀態機的兩個實際行為（囚禁者的轉正流程、
釋放時的落點判定），並不是單純的作弊碼。

排序規則看起來是：先按等級（君主 → 參軍 → 大將 → 軍師 → …），再在同一等級內

原始索引順序**。

## 10. PC 喇叭語音

這是本作最常被提及的特色，但**沒有找到完整的語音清單**。
PTT 討論串（S08）的推文提到了幾句台詞，可作為實測時的比對錨點：

- 「良禽擇木而棲」（招降／登用時）
- 「鼠輩！吾豈懼汝哉！」（推文歸給趙雲）
- 「賊將，他日再戰」
- 「某願施犬馬之力」
- 「天亡我，非吾不能也」（推文者自己也不確定是不是這款遊戲）

這些是十七年前的網友回憶，**逐字準確度不可靠**，只能當搜尋關鍵字用。
