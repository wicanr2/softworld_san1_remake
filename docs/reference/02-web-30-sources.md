## 10. 與手冊轉錄的關係

同目錄的 `01-manual-*.md` 是原版紙本說明書（軟體世界珍藏版 98，4 片裝，NT$300）的
掃描轉錄，是一手資料。它印證了 S04 的多項內容——六個時期的年號與西曆、官階兵力表、
各郡洪水提升率表、計謀的智力門檻與費用、弓箭次數公式——**S04 的可信度因此明顯上調**，
但 S04 仍不能取代手冊。

本份網路資料在手冊存在之後的剩餘價值：

- **加強版的存在與差異**（手冊是原版說明書，完全不提加強版）
- **系列後續作品**（二代、三代、Online 版）
- **兩個流程漏洞**（超級徵兵法、君主捉拿法）
- **`DATA2.GRP` 的資料表位址與結構版面**（手冊不會有）
- **保護機制與 LZEXE 線索**
- **社群記憶中的語音台詞**
