# 文件索引

`CONTEXT.md` 是單一入口（現況、術語、已被推翻的斷言）。
逐輪操作與驗證結果記在根目錄的 [`WORKLOG.md`](../WORKLOG.md)。
**待辦的唯一權威是 GitHub repository 的 open Issues**；`worklist.json` 與
`VERIFICATION-MATRIX.md` 只保存歷史線索，不得用來推翻 Issue 的最新內文、
留言或狀態。這一份是「哪份文件放什麼」。
