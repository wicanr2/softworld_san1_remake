# 文件索引

`CONTEXT.md` 是單一入口（現況、術語、已被推翻的斷言、worklist）。
完成度的數字只在 `VERIFICATION-MATRIX.md`，**待辦的權威是 `worklist.json`**
（`tools/worklist.py verify`）。這一份是「哪份文件放什麼」。

| 目錄 | 放什麼 | 檔案 |
|---|---|---|
| `re/` | **程式碼在哪**：位址、bytes、xref、推論等級 | `00` DOS 服務普查、`01` IDA 管線、`02` 開機到遊戲、`03` 主程式碼圖、`04` 字串表、`05` 戰役層、`06` 四季事件、`07` 五種謀略、`08` 存讀檔、`09` PC 喇叭語音、`10` 動畫 |
| `formats/` | **資料長什麼樣**：每個檔一份，含 round-trip 驗證 | `01` 容器、`02` 郡名、`03` 劇本三表、`04` 資產目錄、`05` 存檔、`06` 配樂、`07` 點陣圖 |
| `spec/` | **授權實作的規格**（`DRAFT`／`READY`／`CONFORMED`／`SUPERSEDED`）| `001` 容器格式、`002` 劇本表、`003` 劇本欄位、`004` 版本與難度、`005` 接原版素材的畫面、`006` 畫面尺寸、`007` 電腦移防、`008` 喇叭音效與語音、`009` 配樂、`010` 畫面轉場、`011` 主戰場的年月 |
| `mechanics/` | **遊戲怎麼運作**：每條斷言帶等級與版本 | `00` 索引、`10` 戰略、`20` 人物、`30` 謀略、`40` 軍事、`50` 事件、`60` 經濟、`70` AI、`80` 勝負、`90` 兩版差異 |
| `design/` | **remake 自己的決定**（不是還原）| `01` AI 三個版本、`02` remake 自選的數值、`03` 主戰場 |
| `reference/` | 說明書轉錄與外部資料 | `01-manual-*`（術語權威）、`02-web-*`（位階最低）|
| `playtest/` | 原版與 remake 同狀態比較 | `01` 一個月的狀態轉移、`02` 規則層的對拍、`03` 畫面的對拍、`04` 玩家自己下的命令 |
| `release/` | 發行相關 | `01` 封包 |

## 常見的找法

| 想知道 | 看哪裡 |
|---|---|
| 某個檔案格式怎麼解 | `formats/` |
| 某條規則的出處與等級 | `mechanics/` |
| 某個數字是原版的還是 remake 選的 | `design/02`，或 `grep -rn Tune internal/` |
| 現在完成到哪 | `VERIFICATION-MATRIX.md` |
| 還剩哪些沒做、憑什麼說沒做 | `worklist.json` ＋ `tools/worklist.py verify` |
| 哪些斷言被推翻過 | `CONTEXT.md` §4 |
| 原版某段文字在哪個位址 | `re/04`（檔案位移）、`re/05` §4（戰術層的 DS 位移）|
| 戰場地圖、地形碼、軍團編成 | `re/05` |
| 五種謀略的選單、候選郡、效果 | `re/07`、`mechanics/30` |
| 存檔的六個項目、年月難度存在哪 | `re/08`、`formats/05` |
| 主畫面怎麼用原版素材拼出來 | `spec/005` |
| 畫面幾列高、憑什麼是 408 不是 350 | `spec/006` |
| 主戰場、開場詞、主選單怎麼拼 | `spec/005`（版面）、`re/05` §2.5–2.6（畫的那一端）|
| 音效與語音怎麼播、槽怎麼分 | `re/09`、`spec/008` |
| 配樂怎麼解、怎麼合成 | `formats/06`、`spec/009` |
| 哪些地方原版會動 | `re/10`（清單 ＋ 已解的三支）、`spec/010`（轉場）|
| 主戰場下方那一行年月怎麼排 | `spec/011` |
| 州郡的填色圖樣 | `formats/07` 的 `EGAFILL.PAL` 一節 |
| 電腦諸侯用計的整條鏈 | `mechanics/70-ai` §2.13.7 |
