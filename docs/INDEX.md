# 文件索引

`CONTEXT.md` 是單一入口（現況、術語、已被推翻的斷言）。
**待辦的唯一權威是 GitHub repository 的 open Issues**；`worklist.json` 與
`VERIFICATION-MATRIX.md` 只保存歷史線索，不得用來推翻 Issue 的最新內文、
留言或狀態。這一份是「哪份文件放什麼」。

| 目錄 | 放什麼 | 檔案 |

## 常見的找法

| 想知道 | 看哪裡 |
|---|---|
| 某個檔案格式怎麼解 | `formats/` |
| 某條規則的出處與等級 | `mechanics/` |
| 諸侯記錄哪些位元組原版真的碰過、加強版的月底結算入口在哪 | `re/11` |
| 原版自己打完一局要幾年、怎麼讓示範模式跑起來 | `playtest/05` |
| 某個數字是原版的還是 remake 選的 | `design/02`，或 `grep -rn Tune internal/` |
| 現在完成到哪 | `VERIFICATION-MATRIX.md` |
