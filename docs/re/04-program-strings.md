# 主程式的字串表

`AA.EXE` 的資料段裡有整套介面文字。這一份記的是**介面字串**——選單、
提示、格式字串、資源檔名。它們是規格證據：remake 的每一個選單、每一個
欄位標籤都要對得回這裡的某一行。

抽取工具是 `cmd/san1strings`（**本儲存庫不含原版檔案，路徑自備**）：

```sh
tools/go.sh run ./cmd/san1strings -f /path/to/AA.EXE            # 全部掃一遍
tools/go.sh run ./cmd/san1strings -f /path/to/AA.EXE -at 0x46c02  # 看完整條
```

判準是掃 NUL 結尾字串，每個位元組要嘛是可列印 ASCII、要嘛是合法的 Big5
雙位元組對，且整串以 cp950 解得開。選單是一整條含 `\n` 的字串，
所以引用成規格證據之前要用 `-at` 看完整條——只看掃描結果的第一行
會少掉後半。

位移是**檔案位移**（映像內），不是執行期 `seg:off`。

> 遊戲的對白與旁白（單挑叫陣、登用應答、計謀成敗、繼位、結局詩句等）
> 同在這個表裡，本文件**不轉錄全文**——那是原版的內容，不是介面規格。
> 需要的部分在各節以「有幾條、在哪個位移、屬於哪一類」的形式記錄。

## 4. 主戰場的指令（戰術層）

這一節是**戰術層最直接的規格證據**：原版的主戰場有兩層指令選單。

部隊指令（`0x46be2` 的提示是 `%s主公請下%s(%2d)%s的命令(0-8):`）：

```
0x46c02  1.移動 2.對戰 3.快戰
         4.死戰 5.弓箭 6.策略
         7.查看 8.退兵 0.休息
```

選 `2.對戰` 之後進入單位層，提示 `%s(%d/%d)(0-4):`（`0x46f90`）：

```
0x46fa0  1.行軍 2.單挑 3.攻擊
         7.查看 0.休息
```

選 `6.策略` 之後：

```
0x46df3  1.火攻 2.水洽 3.陷阱
         4.誘敵 5.燒糧 6.圍攻
         (1-6):
```

⚠ **計謀的編號以這裡為準。** 手冊把誘敵排第 3、陷阱排第 4，
程式是**陷阱第 3、誘敵第 4**。程式是實際跑的東西，手冊是二手轉錄。

方向鍵盤（`0x46fdf`、`0x47005`、`0x4701e`、`0x46e24`）都是同一個排法：

```
 4  5  6
 1  2  3
```

## 13. `.OKR` 的線索

`R%03d.OKR` 這個格式字串在 `0x495f2` 出現三次。已知的事實：

- 容器裡的 `.OKR` 名稱是 `R000.OKR`–`R483.OKR` 加上 `R498`、`R499`，
  共 465 項（`DATA2` 418 項、`DATA3` 47 項）——與格式字串一致（`L0`）
- 這三份格式字串位在**存檔常式與火攻／水淹死因訊息之間**的區域（`L0`）
- 465 不是 42 的倍數，所以**不是一郡一張圖**（`L0` 的算術）
- 長度多半是 50 的倍數加一，自相關約 0.55，判為壓縮過（`docs/formats/04`）

還不知道的是索引怎麼算出來的，以及一項裡裝的是什麼。要往下走得反組譯
`0x495f2` 的三個引用點，看它們拿什麼當 `%03d`。

「郡地理誌」在查看選單裡是第 5 項（§2），對應的旁白是 `0x4f9e6`
`此乃本郡之地理圖誌`——但**那條字串與 `R%03d.OKR` 相距四萬個位元組**，
兩者的關聯目前只是推測，不是證據。

`Gold or Rice`、`Double Seal event`、`CTMG:%dGen:%s So%d`、
`Picture_Show_Byte`／`_Mode`、`Picture_Show_Mode`。

`War Gen <1 or >50` 與 `This_State_<1_or_>50` 兩條都指向 50——
與 `本郡已有50位將軍` 是同一個上限。`Double Seal event` 指向玉璽只有一顆。

## 16. 對白與旁白（不轉錄全文）

`0x4f952`–`0x50110` 是一整段對白表，約 90 條，可分成幾類：

| 類別 | 大致範圍 | 條數 |
|---|---|---|
| 軍師諫言（內政、商業、軍事的提示）| `0x4f9e6`–`0x4fb34` | 約 18 |
| 尋訪與登用的應答 | `0x4fb4d`–`0x4fd3b` | 約 16 |
| 任命軍師、太守、自治 | `0x4fc6f`–`0x4fcdd` | 約 6 |
| 五種平時計謀的說明與成敗 | `0x4fd54`–`0x4fdc6` | 約 8 |
| 戰場計謀的提示 | `0x4fddd`–`0x4feae` | 約 10 |
| 單挑叫陣與勝敗 | `0x4feb7`–`0x4fffc` | 約 16 |
| 被擒的處置 | `0x4ffc1`–`0x5002d` | 約 6 |
| 繼位與結局 | `0x50063`–`0x500ae` | 約 5 |
| 用計失敗的三種理由 | `0x50110`–`0x5013a` | 3 |

其中三條是規格證據，記在這裡：

- `0x50110` `資金不足  無法用計`
- `0x50123` `將軍謀略不足  無法用計`
- `0x5013a` `天侯地理因素  無法用計`

用計的三個門檻——**錢、智力、天氣地形**——原版自己講得很清楚，
與手冊 p.32–34 的條件一一對上。

結局詩句在 `0x501b9`：`天地英雄氣    千秋尚凜然`。
