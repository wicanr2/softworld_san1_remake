# 07：戰略層的五種謀略

`[base]`。分派器在 `0x2c2ee`，五支效果常式各自獨立：

```
0x2c2f0  1 驅虎吞狼  0x2c9d8
0x2c2fa  2 遠交近攻  0x2c32e
0x2c300  3 偽書使疑  0x2ce66
0x2c306  4 策反人民  0x2d34c
0x2c30c  5 聯合出兵  0x2d88c
```

選單字串在 `DS:0x8260`（`1.驅虎吞狼 2.遠交近攻\n3.偽書使疑 4.策反人民\n5.聯合出兵\n請選擇:`）。

## 1. 前置條件（`0x2c225`–`0x2c281`）

```
si = 72 × 州郡[我方郡].所屬(offset 30)     ; 諸侯記錄
ax = 諸侯[勢力].軍師(offset 6)
軍師 == 0xFFFF                    → 擋下
人物[軍師].領地(offset 19) == 我方郡  → 放行
州郡[我方郡].主事者(offset 32) 那個人的身分(offset 17) == 0（君主） → 放行
否則 → 擋下，印 DS:0x8246「只有軍師所在郡\n才能執行」
```

**沒有金的檢查、也沒有扣金**：dispatcher 與五支效果常式都沒有碰
州郡 offset 18。策反人民那支動到金，動的是**目標郡**的金（效果不是費用）。
所以平時的五種謀略不花錢（`L0`）。

## 2. 候選郡怎麼算出來

五支都用同一塊暫存：段 `[0xa9e4]` 的 `0x2102` 起 **43 個 word**
（`0x2c3e7` 的迴圈上限是 `0x2b`），`0xFFFF` ＝ 不可選、`0` ＝ 可選。
郡編號 1–42 直接當索引。

鄰郡讀的是州郡 offset 45–54（10 格，`0xFF` 是空，`docs/spec/003` §3.2）。

| 計謀 | 選單 | 條件 | 位址 |
|---|---|---|---|
| 驅虎吞狼 | `<驅虎吞狼>出使那一郡` | 有主、非我方 | `0x2caa6` |
| | `<驅虎吞狼>驅使攻打那一郡` | 出使郡的鄰郡、有主、非我方、非出使郡那一方 | `0x2cb4c` |
| 遠交近攻 | `<遠交近攻>出使那一郡` | 有主、非我方，**而且鄰郡的鄰郡裡有我方的郡** | `0x2c401`／`0x2c453` |
| | `<遠交近攻>聯合攻打那一郡` | 出使郡的鄰郡、有主、非我方、非出使郡那一方，**而且與我方相鄰** | `0x2c53e`／`0x2c5d3` |
| | `<遠交近攻>聯合我方那一郡` | 與攻打目標相鄰、屬我方 | `0x2c689` |
| 聯合出兵 | `<聯合出兵>從我方那一郡出兵` | 我方的郡，全部 | `0x2d95f` |
| | `<聯合出兵>聯合攻打那一郡` | 出兵郡的鄰郡、有主、非我方 | `0x2d9f8` |
| | `<聯合出兵>聯合我方那一郡合攻` | 攻打目標的鄰郡、屬我方，**而且不是出兵的那一郡** | `0x2dab0` |
| | `<聯合出兵>聯合守方那一郡合守` | 守方郡的鄰郡、與守方同一勢力 | `0x2dc6e` |

聯合出兵的第三個選單一個都挑不到時印 `DS:0x8543`「無法聯合出兵」
退回選單——「聯合」至少要兩個郡。

遠交近攻的「遠」只有兩步：出使的對象要**隔著一個郡就碰得到我方**。
驅虎吞狼沒有這條——教唆的是兩個別人的郡互打，我方不必在附近。

## 3. 軍師先預測，準不準看他的謀略

三支帶使者的計謀（驅虎吞狼 `0x2ca50`、遠交近攻 `0x2c774`、
偽書使疑 `0x2cede`）在真的動手之前先跑一次判定給玩家看：

```
0x2c780  RND(5) + 80  <  es:[0x16f2]（我方軍師的謀略）→ 往下，否則直接執行
0x2c79d  0x2dd66(我方郡, 出使郡, 使者魅力)
             ≠ −1 → 訊息 0x1a1（會成功）
             = −1 → 訊息 0x1a2（會失敗）
0x2c7d3  RND(18) + 80 >  軍師的謀略 → 訊息改成 RND(2) + 0x1a1（隨機）
0x2c876  印 DS:0x832a「主公是否繼續呢(Y/N):」；按 N 回 0xFFFF 取消
0x2c896  真的執行
```

`es:[0x16f2]` 是該勢力軍師的謀略（`docs/spec/003` §2.7；同一道門在
`0x18a90` 是軍師勸諫）。**兩道門的意思不同**：第一道決定軍師開不開口，
第二道決定他說的準不準——`RND(18)+80` 是 80–97，謀略 98 以上的軍師
永遠說實話，謀略 80 以下的軍師連開口的機會都很少。

判定本身（`0x2dd66`）沒有擲骰，所以軍師只要開得了口、又沒被隨機化，
預測就等於結果。

## 4. 三支的結局是發動一場戰役

戰鬥子系統是 `battle(攻方郡, 攻方援郡, 守方郡, 守方援郡)`
（`0x20200`，`docs/re/03` §戰鬥子系統），`−1` ＝ 沒有那一支。

| 計謀 | 呼叫點 | 四個郡 |
|---|---|---|
| 驅虎吞狼 | `0x2ce5b` | `(出使郡, −1, 被驅使去打的郡, −1)` |
| 遠交近攻 | `0x2c9cd` | `(我方出兵郡, 出使郡, 聯合攻打的郡, −1)` |
| 聯合出兵 | `0x2dd57` | `(我方出兵郡, 我方另一郡, 聯合攻打的郡, 守方援郡)` |

這就是說明書 p.26「助攻軍必須運用謀略才能得到」的出處。
**驅虎吞狼我方完全不參戰**——兩個格子都是別人的郡。

聯合出兵**不判計謀成不成**（它不需要說服誰，也沒有使者選單）。
它那一次 `0x2dd66` 判的是**守方求不求得到援軍**（`0x2dc51`，
第三個參數寫死 `0x46` ＝ 70）：

```
0x2dc51  0x2dd66(我方郡, 聯合攻打的郡, 70)
             ≠ −1（我方壓過守方）→ 跳過求援，守方援郡留 0xFFFF
             = −1                → 0x2dc6e 找守方的援軍
0x2dc6e  守方郡的鄰郡裡與守方同一勢力的都標成可選，電腦取掃到的最後一個
0x2dd0c  那個勢力的諸侯 offset 0 == 1（玩家操縱）→ 讓玩家自己挑
0x2dd34  印「\n守方派出援軍」
```

魅力填 70 是因為 `0x2dd66` 對魅力的規則是「低於 70 才扣分」——
填一個不影響結果的值頂著。

## 5. 偽書使疑的效果（`0x2d1fa`）

參數是 `(細作去的郡, 使者魅力)`。先用 `0xf17:0x0aae(郡, 2)` 取那個郡的
武將名單（結果放在段 `[0xa9e8]` 的 `0x58c` 起，筆數在段 `[0xa9e6]` 的
`0x0c`），再逐一處理：

```
0x2d234  al = 人物[名單[i]].忠誠(offset 16)
0x2d23a  忠誠 >= 使者魅力 → 跳過
0x2d24f  RND(魅力 ÷ 2)
0x2d257  cx = 250 − RND(魅力 ÷ 2) − 魅力
0x2d261  忠誠 ← 忠誠 × cx ÷ 250
0x2d287  算成負數 → 歸零
```

**門檻與幅度都跟著使者的魅力走**：魅力愈高牽連的人愈多、掉得也愈多。
魅力 100 時係數落在 0.40–0.60，魅力 60 時是 0.64–0.76。
迴圈不挑身分——君主在自己的郡裡也照算。

訊息是 `DS:0x843e`「%s主公, 有人在\n%s散佈謠言」，兩個 `%s` 依序是
目標郡所屬諸侯的君主名（人物 offset 0）與郡名（州郡 offset 0x480 起），
`sprintf` 在 `0x2d2ec`；配圖是 `DS:0x8458`「`SCG13.IMG`」。

**電腦諸侯的計略走的也是這一支**（`0xe79e` 的
`lcall 0x2c21:0x0fea`），而且五種計謀裡它只用這一種
（`docs/mechanics/70-ai` §2.13.7）。`0x2d1fa` 與策反人民的效果
`0x2d6e0` 的 far 呼叫端各只有一個，玩家那兩條是同段的 near call。

## 6. 挑名單的共用常式 `0xf17:0x0aae`（＝ `0xfc1e`）

`buildRoster(郡, 模式)`。掃全部 350 個人物槽，合格的槽號依序寫進
段 `[0xa668]` 的 `0x58c`，筆數放段 `[0xa666]` 的 `0x0c`。
模式的跳躍表在 `CS:0x0c80`（＝ `0xfdf0`），七個入口：

七個模式全部要求**所在郡（offset 19）＝ 指定郡**，差別在身分
（offset 17）與謀略（offset 9）：

| 模式 | 入口 | 身分 | 另加 |
|---|---|---|---|
| 1 | `0xfc3a` | 8 或 10（在野）| — |
| 2 | `0xfc78` | 0, 1, 2, 3 | — |
| 3 | `0xfc9e` | 0, 1, 2, 3 | 謀略 >= 0x50 |
| 4 | `0xfcf2` | 1, 2, 3, 8, 10 | — |
| 5 | `0xfd42` | 1, 2, 3 | — |
| 6 | `0xfd7c` | 1, 2, 3 | 謀略 >= 0x50 |
| 7 | `0xfd96` | 3 | — |

模式 2 與 5、3 與 6 各差一道「身分 ＝ 0 就直接收」。所以**偽書使疑
（模式 2）連君主一起算，挑使者（模式 5）不會挑到君主**。

搭配的排序是 `0xf17:0x03b0`，排完之後名單第一位就是要的那一位
（挑使者時取的是魅力最高者）。

## 7. 州郡 offset 32 是主事者

前置條件（§1）與五支計謀（`0x2c82e`／`0x2ccc4`／`0x2d094`／`0x2d57a`）
都直接讀州郡 offset 32 取出「這個郡現在誰主事」，`u16`、`0xFFFF` ＝ 沒有。
**它是執行期維護的狀態**：開局之後有十三處寫它（`0x0d705`、`0x132ee`、
`0x14d36`、`0x19500`、`0x1958b`、`0x1cc3c`、`0x1d66b`、`0x1d709`、
`0x2461a`、`0x2579d`、`0x26413`、`0x26557`、`0x2695c`）。

六個劇本逐郡驗過：那個人的勢力與所在郡都與郡本身相符，身分是君主（0）、
軍師（1）或太守（2）——軍師也能主事（劇本 004 的周瑜、劇本 006 的
司馬懿）。無主的郡一律 `0xFFFF`。

**「勢力相符」是出貨劇本的性質，不是執行期的不變式（`L1`）。** 那十三處
寫它的地方之外沒有人維護它，也沒有任何一支常式在讀它之前檢查「這一位的
勢力還等於郡的所屬嗎」。月度對拍載入舊進度得到的局面裡就有一個：潁川
（所屬 4）的主事者是荀彧（**勢力 5**），原版整輪跑完不動它——42 個郡裡
只有這一個不符。remake 這一邊要照做，否則混編的郡每個月會被重推一次
（`docs/playtest/02`）。
