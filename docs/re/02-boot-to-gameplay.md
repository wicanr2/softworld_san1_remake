# 02：原版從開機走到遊戲設定

`L1`（可重現的執行）。素材是 `org_game/三國演義`（base），執行器是
`dosgolem-san` 分支 `san1-msc-oracle`。

## 1. 開機鏈

三層，每一層都是完整的 MSC 程式（自己縮 PSP 區塊、自己起 far heap、
自己跑啟動碼）：

```
AA.EXE (354,960)
  └ 自解壓後把一段 stub 搬到 9FE4:0000，從那裡發出 int 21h AH=4Bh AL=03
      └ DaTa0.gRp (42,488)   載到 0110:0000，重定位加數 0110
          （檔名大小寫混雜是 overlay 載入器的寫法，不是筆誤）
          └ DaTa5.gRp (145,378)  同樣載到 0110:0000，蓋掉上一層
```

`DATA5.GRP` **是主程式不是資料容器**。`10.BAT`／`20.BAT` 做的是
`DEL DATA5.GRP` ＋ `COPY 10.GRP DATA5.GRP`，而 `10.GRP` 與出貨的
`DATA5.GRP` 逐位元組相同。

## 2. 走到遊戲設定要的東西

按時間順序：

| 什麼 | 為什麼 |
|---|---|
| 三個裝置選項的按鍵 `1`／`2`／`2` | `int 21h AH=08`，只收 `1` 或 `2` |
| 一個 `Enter` | 開場動畫的續行 |
| MCB 鏈同步 | 原版沿鏈釋放記憶體、沿鏈算可用量（`dosgolem/docs/spec/012`）|
| handle 號碼重用 | 號碼爬到 20 之後 MSC 的低階 I/O 表放不下（`spec/013`）|
| 硬體鍵盤 IRQ1 ＋ 埠 `0x60` | 主選單自己裝 IRQ1 處理常式，不從 BIOS 讀鍵（`spec/014`）|
| EGA 圖形控制器 | 少了 latch，畫面是有規律的直線雜訊（`spec/011` §4）|

## 3. 目前的操作配方

```sh
DOSGOLEM_ORIG=~/cht/softworld_san/org_game tools/go.sh run ./cmd/probe \
  -exe "/orig/三國演義/AA.EXE" -root "/orig/三國演義" \
  -steps 3000000000 -keys '122' \
  -keys-at '250000000:\r,900000000:1,1500000000:1' \
  -dump-ega '640x350=out.png'
```

⚠ **那幾個指令數是量出來的不是算出來的**，而且會隨執行器的改動而變。
按鍵早送一步就會被前一個畫面吃掉，晚送則是多跑幾億道指令而已——
所以寧可晚不要早。要當回歸測試用的話，觸發條件該換成程式行為
（例如某個畫面畫完），不是指令數。

另一個坑：字元佇列的頭被一個程式不要的鍵卡住時，**後面的鍵全部進不去**
（`int 16h AH=01` 只看不取）。多餘的鍵不是無害的。

## 4. 走到哪裡

| 畫面 | 內容 |
|---|---|
| 裝置選單 | `Music` / `Graphic` / `Disk` 三題（文字模式）|
| 發行商識別 ＋ 開場 | EGA 640×350 |
| 主選擇單 | 開始新遊戲／載入舊進度／使用楷書字／使用隸書字／音樂欣賞／回作業系統 |
| 選擇年代 | 中平六年／興平二年／建安六年／建安十三年／建安二十年／黃初元年 |
| 君主選擇 | 中國地圖（42 個編號郡）＋ 六位君主頭像：劉備／曹操／孫堅／袁紹／袁術／董卓。左側直排「中平六年元月」|

字體（楷書／隸書）是主選單的選項，不是設定檔。

## 5. 打開的檔案

到君主選擇為止共 18 次開檔（handle 會重用，所以數字不是同時開著的數量）：

```
DATA0.GRP
DATA1.IDX  DATA1.NAM  DATA1.GRP ×2
DATA5.GRP
DATA1.IDX  DATA1.NAM              ← 主程式重開一次
DATA2.IDX  DATA2.NAM
DATA3.IDX  DATA3.NAM
DATA1.GRP ×2  DATA2.GRP ×2  DATA3.GRP ×2
```

三組容器的開法都是 `fopen(name,"rb")` → `fclose` → `fopen(name,"r+b")`，
第二次要的是**讀寫**。主程式的資料段有一張檔名表，第二組帶 `B:` 前綴
（`B:DATA3.GRP`），那是雙磁碟機安裝的路徑。
