# 12：訊息框與片語表

`[base]`。原版每一則對白都由訊息常式 `0x3273e` 畫：說話者的肖像、名字、
白色的泡泡與兩行字，然後（語音開著時）播三段語音。版面的規格在
`docs/spec/005` §9；這一份記常式本身與它讀的片語表。

## 1. 參數與流程（`0x3273e`–`0x32df8`，`L0`）

```
msg(x1, y1, x2, y2, side, 肖像號, 名字 far*, 片語 a, 片語 b, 片語 c)   ; 11 個 word
```

| 位址 | 做什麼 |
|---|---|
| `0x3274b`–`0x3277c` | 掃人物表 350 筆，找肖像號等於參數的那一位（`0x222b` ＝ offset 27）——**只拿來算語音速度** |
| `0x3277e`–`0x327d9` | 語音速度 ＝ `max(智, 武)`：智 > 武 用 `智 ÷ 2 + 105`、否則 `武 + 105`；智 > 90 改 `智 + 75`；上限 190 |
| `0x327de` | `side == 0xFFFF` → 肖像在左（`0x327e7`），否則在右（`0x3295e`） |
| `0x32808`／`0x32983` | 畫肖像 `0xf7b4(x, y, 肖像號, 0, side)`——side 同時是翻面旗，左邊那張翻 |
| `0x3282b`／`0x329a6` | 名字 `0x33d8:0x104e(x, y, 名字, fg, bg=0)`，左 fg 12、右 fg 10 |
| `0x3285f`–`0x3293a`／`0x329da`–`0x32ada` | 白底、上下緣、左右緣、四條尾巴（`es:0x252e`／`0x17be`／`0x20e6`） |
| `0x32ae2`–`0x32b13` | 三個片語號各夾在 0..499 |
| `0x32b18`–`0x32ba8` | 語音開著（`es:0x3148 != 0`）時各組 `R%03d.OKR` 載進槽 1–3（`docs/re/09` §6.3） |
| `0x32bab`–`0x32bc4` | 一行的位元組數 ＝ `((x2 − x1 − 79) ÷ 16) × 2` |
| `0x32bd9`–`0x32ce7` | 三段接成一串到 `DS:0x314e`：號 < 350 → 人物表 `0x399b:0x2210 + 號×30` 的名字（6 byte，兩字名前後各一空白）；≥ 350 → 片語表 `es:[0x9382 + 號×4]`（far 指標） |
| `0x32ced`–`0x32d35` | 超過一行的部分搬到 `DS:0x3cc4`，第一行在那裡截斷 |
| `0x32d4d` | `RND(8)` → 字色 |
| `0x32d67`／`0x32d93` | 兩行各 `0x33d8:0x1d4e(x, y, str, 字色, 15, 1, 2, 0)`：16×32 的字 |
| `0x32d9b`–`0x32dd1` | 語音開著時依序 `speak(槽 1..3, 速度)` |
| `0x32dd4`–`0x32dec` | 語音開著且 `es:-0x7a40 == 0xFFFF` 才 `0x1058:0xe80`（等）；否則直接回 |

**訊息常式自己不等鍵**：語音關著時畫完就回，停多久由呼叫端決定
（出頭與老死的呼叫端各自接一次 `0x1058:0xe80`，`0x16278`／`0x14850`）。

## 3. 誰說了什麼

元月與繼承的六個呼叫端在 `docs/spec/005` §9；主畫面命令那一層的 38 個
（軍師勸諫、人事與計略的回話、宣戰）在 §9.6（Issue #51）；戰場、對戰
子畫面與單挑的在 §9.7（Issue #52）；`0x3273e` 的 111 個 `lcall` 位址列在
`docs/re/09` §6.2 那一次掃出來的清單裡。

讀參數的方法：從 `lcall $0x3273,$0xe` 往回收 11 個 `push`（依序 x1, y1,
x2, y2, side, 肖像, 名字 off, 名字 seg, 片語×3；`mov $imm,%reg` 再 `push`
的解成立即值），說話者看 `0x1e × 誰` 那一乘的運算元：`es:0x3b96` 是
勢力的軍師、`es:0x4a0(bx)`（bx ＝ 0xb0 × 郡）是郡的主事者、其餘是
區域變數（目標、使者、君主）。
