# 014：原版素材主畫面上的指令表、子選單、挑選清單與分頁

狀態：`READY`

範圍：`ui.DrawArtSession`（接原版素材的主畫面，`cmd/san1` 的預設）上，
**玩家下令時看得到的那幾樣東西**：十項指令表、類別子選單、挑選清單、
數字輸入、分頁、結局訊息。郡的資料面板本身在 `docs/spec/005`。

證據等級：`L1`（原版在 dosgolem 裡實跑，`TestZZSubMenuScreens` 存圖、
逐列量墨水）＋ `L0`（子選單的字串，`docs/re/04` §2）。版本：`[base]`。

## 1. 為什麼有這一份

這個畫面先前**只畫 `View.Prompt`**：打開子選單、挑選清單或分頁，畫出來
與沒打開差 0 個位元組。玩家按 `9` 什麼都看不到，挑將領時看不到有哪些人，
數字輸入看不到自己打了多少——預設畫面上只能靠記憶操作。文字版
（`ui.DrawSession`）一直都有畫，所以兩者的差別在測試裡看不出來。

## 2. 原版長什麼樣（`L1`）

從開機到主畫面的同一個快照，分別送 `1`–`9` 加 `Enter`，量兩塊面板裡
每一段墨水的範圍與顏色（`internal/parity` 的 `TestZZSubMenuScreens`；
圖在 `workplace/shots/submenu/`）。

### 2.1 主提示時，上面板是十項指令表

**原版等玩家下令時，上面板畫的不是郡的資料，是指令表**；郡的資料要按
`0.狀態` 才出來（`orig-main.png` 那一張是讀檔之後的狀態頁）。

| 項目 | 量到的 |
|---|---|
| 版面 | 兩欄，左欄 0–4、右欄 5–9 |
| 欄 | 左 x = 424、右 x = 536 |
| 列 | 列頂 y = 52，每列 +48（52／100／148／196／244）|
| 編號「`0.`」| 16×16，**貼在列的下半**（列頂 +16，墨水 y 71–81），白（15）|
| 名稱 | 32×32 雙倍字，接在編號後面（左欄 x = 440、右欄 552），墨水 y 54–81 |
| 名稱顏色 | **偶數項黃（14）、奇數項洋紅（13）**：狀態黃、查看洋紅、軍事黃…商業洋紅 |
| 底色 | 青（3），與郡的資料頁同一塊面板 |

### 2.2 子選單畫在下面板

| 項目 | 量到的 |
|---|---|
| 位置 | x = 424，四行 y = 300／316／332／348 |
| 顏色 | 黃（14），底色綠（2）|
| 內容 | `docs/re/04` §2 的原版字串，**斷行照原樣**：項目之間一個半形空白，最後一行是提示字 |

逐群對過：`sub-1` 第一行兩群 x 424–503／512–591 就是「`1.選擇州郡 2.將軍列表`」
（十格 ＋ 一格空白 ＋ 十格），`sub-9` 三群 424–471／480–527／536–583 就是
「`1.結束 2.儲存 3.音樂`」。子選單打開時上面板**維持指令表**（`sub-9`
的上面板與 `sub-0` 逐段相同）。

⚠ **原版的斷行不是單純的「塞得下就接」**：九類裡八類都是，只有「軍事」
一行一項（`1.調動軍隊\n2.發動戰役\n3.運送錢糧\n請下命令:`），兩項其實
塞得下。remake 照原樣，把這一類記成例外（`subMenuPerLine`）。

提示字三種：查看與其他是 `請選擇:`，軍事到君主是 `請下命令:`，謀略是
`那一頂:`（原版字，同 `洪水防冶` 照原樣留著）。

### 2.3 分頁蓋掉上面板

「查看 → 將軍列表」之後，上面板整塊改成**藍底（1）**，一頁一位將軍、
欄位直排；下面板**第二行**（y = 316）寫 `請按任一鍵`。

### 2.4 類別 7 與 8 在這一局沒有被接受

送 `7`／`8` 之後上面板換回郡的資料、下面板回到主提示——那是這一局的
條件不成立（原因沒追），不是另一種版面。

## 3. remake 的做法

### 3.1 上面板三種內容

| 條件 | 上面板 |
|---|---|
| 類別子選單打開 | 指令表（§2.1）|
| 挑選清單或數字輸入 | 清單：標題（黃）＋ 一行一項（白），24 格 × 14 行 |
| `View.Status` 為真 | 郡的資料（`docs/spec/005`）|
| 其他 | 指令表（§2.1）|

**`View.Status` 由玩家打開**：主提示按 `0`、或用方向鍵換郡時打開；打開
類別子選單時關掉。原版的「`0.狀態`」就是這個開關；方向鍵換郡是 remake
自己的操作（原版換郡走「查看 → 選擇州郡」），換了郡當然要看得到那一郡。

指令表的雙倍字寬度是照原版兩個全形字排的（64 像素）：右欄的名稱從 552
起，到面板內緣（624）只剩 72 像素。**十項裡有一項超過 4 格，整張就改畫
一倍字**、垂直置中在那一列——同一張表大小混雜看起來像排版壞了。中文十項
都是兩個字，所以永遠是雙倍字；英文（`Military`）與日文（`その他`）是一倍字。

### 3.2 下面板

類別子選單照 §2.2（`ui.SubMenuLines`）。**譯文排不進下面板的四行 × 24 格
時**，子選單改畫在上面板一行一項，下面板只留提示字；上面板也放不下（一項
超過 24 格）就蓋整個內容區。三個語系量出來的去處（`TestSubMenusShowInFullInEveryLanguage`）：

| 語系 | 排不進下面板的類別 |
|---|---|
| 繁中 | 無（九類都在下面板，與原版相同）|
| 日文 | 無 |
| 英文 | 1 查看、3 兵士、7 君主、9 其他 → 上面板；8 謀略（`2.Befriend Afar, Attack Near` 28 格）→ 內容區 |

其餘時候放提示或最後一則訊息，
**最多四行**（原版的主提示用兩行，事件訊息常常更長，四行是面板放得下的量）。
結局時第一行是結局訊息。

### 3.3 分頁蓋在整個內容區

remake 的分頁是**寬表格**（將軍列表一列約 53 格），塞不進上面板的 24 格。
所以蓋在地圖加右側面板那一整塊：x 72–632、y 36–372（70 格 × 21 行），
藍底照原版；標題黃、內容白，最後一行是關閉的提示。挑選清單的標籤寬過
上面板時（例如存檔槽的描述）也改畫在這一塊。

**表格的欄寬依內容決定**（`cells.Columns`）。先前寫死成照中文兩個字挑的
寬度，而 `cells.Pad` 會截斷：英文的 `Governor` 與 `Gold` 黏成
`GovernorGold`、`Flood Risk` 被截成 `Floo`，職位名被截到六格；中文的
將軍列表把**將軍的**忠誠欄標成「民眾」（`fld.loyalty` 是民眾忠誠，截到
四格）。表頭改用一組表格專用的短欄名（`col.*`），三個語系在劇本 001
開局的每一個郡、勢力與將軍上都在 68 格內
（`TestPagesFitTheOverlayInEveryLanguage`：繁中最寬 60、英文 67、日文 52）。

### 3.4 「其他」有十項

remake 在「其他」加了兩項（`docs/design/02` §5），前兩行與原版逐字相同，
第三行接上第九項，第十項與提示字擠在第四行：

```
1.結束 2.儲存 3.音樂
4.音效 5.延時 6.戰役
7.年號 8.語音 9.電腦AI
0.電腦指令 請選擇:
```

## 4. remake 差異（登記在案）

| 項目 | 原版 | remake |
|---|---|---|
| 分頁 | 一頁一位將軍，蓋上面板 | remake 自己的表格頁，蓋整個內容區 |
| 挑選清單、數字輸入 | 沒量 | 畫在上面板（清單寬時蓋整個內容區）|
| 下面板的行數 | 主提示兩行 | 最多四行 |
| 輸入游標 | 紅色圓點（12）| 沒畫 |
| 英日文的指令名 | —（原版只有中文）| 放不下雙倍字就畫一倍字 |
| 「其他」第九、十項 | 沒有 | §3.4 |
| 譯文排不進下面板的子選單 | —（原版只有中文）| 上面板一行一項，或蓋內容區（§3.2）|
| 方向鍵換郡時顯示郡的資料 | —（原版沒有方向鍵換郡）| 打開 `View.Status` |

## 5. 驗證

- `TestArtSessionDrawsWhatThePlayerNeeds`：子選單、挑選清單、數字輸入、
  分頁、結局，每一樣打開與沒打開畫出來**都要不同**（先前全部是 0）。
- `TestSubMenuLinesMatchTheOriginal`：中文的八類與原版字串逐行相同，
  「其他」前兩行相同。
- `TestSubMenusShowInFullInEveryLanguage`：三個語系、九類都完整畫得出來
  （下面板、上面板或內容區），而且中文九類都在下面板。
- `TestCommandMenuLayout`：指令表的格位與顏色照 §2.1，三個語系都不畫出上面板。
- `TestPagesFitTheOverlayInEveryLanguage`：分頁三個語系都在內容區的 68 格內。
- `cells.TestColumnsNeverTruncate`：表格的欄名不截、欄與欄不黏。

## 6. 還沒做的

- **郡的資料面板的欄名是寫死的中文**（`drawArtStatus`）：英日文下也顯示
  「土地價值」「人望」。那一格的槽位是原版版面決定的（標籤 ＋ 靠右的數值
  共 12 格），英文要用短欄名才塞得進，還沒做。
- **左側直條的年月在英文下一個字母一列**（`Zhongping 6 month…`）：
  原版直排七個全形字，英文要換一種寫法。
