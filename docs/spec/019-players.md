# 019：玩家人數 0–16、逐位選君主、照郡的順序輪流下令

狀態：`CONFORMED`（2026-09-17，§4 四項對拍通過；使用者裁定 2026-09-17：跟原版一樣支援 0～16 人）

範圍：開新局的「請問有幾人玩(0-%d)」、逐位選君主、沒人選的新君主欄、
0 人的電腦自動示範模式，以及月迴圈遇到玩家的郡時停下來讓那一位玩家下令。

證據等級：`L0`（執行期碼段 `workplace/dump/code-00b000.bin`，字串在
`dgroup-0427e0.bin`）；開局的表、畫面與月迴圈的停點 `L1`（§4）。
版本：`[base]`。加強版的同一段沒有逐行比過，不外推。Issue #68。

## 1. 開新局（`0x11fa5` → `0x12072(君主數)`）

```
es:[0x3120 + 槽×2] ← 0xFFFF（十六格）            ; 誰選了誰：玩家序號，−1 ＝ 沒人
es:0x31bc ← 0                                  ; 選君主的頁首
0x124ca(君主數)                                  ; 畫第一頁六位
「請問有幾人玩(0-%d):」                            ; 0x33d8:0x1d4e(424, 340, 字, 13, …)
人數 ← 0x33d8:0x1ef8(0 … 君主數)                    ; 負數重問
人數 == 0：
    訊息「電腦自動示範模式」 → 等一個鍵
    es:0x2f72（延時）← 2；DS:0x5b02 ← 0；es:0x2174（戰役顯示）← 0
人數 > 0：
    es:0x2174 ← 1；DS:0x5b02 ← 0xFFFF
    for i = 0 .. 人數−1：
        「第%d位,請選擇(1-%d):」
        n ← 0x33d8:0x115e(頁首+1, min(頁首+6, 君主數))
        n == 0xFFFE（空白鍵、沒打數字）→ 頁首 += 6，超過歸 0，重畫這一頁，重問
        n < 1 或 es:[0x311e + n×2] ≠ 0xFFFF（已被選走）→ 重問
        es:[0x311e + n×2] ← i                        ; 槽 n−1 被第 i 位選走
        在那一格肖像下緣印 %2d（i+1）                    ; docs/spec/005 §9.4「已選」
「請設定難度(1-10):」 → es:0x30fe                   ; 0 人也問
依難度改寫各諸侯的 AI 等級                             ; game.AILevelsAtStart
選走的槽裡君主槽 ≥ 346（新君主欄）→ 0x12df4 分配能力   ; docs/spec/013
被選走的槽：諸侯 offset 0 ← 1（玩家）                  ; 0x123e5
君主槽 ≥ 346 而且沒人選：人物 offset 17 ← 12、18／19 ← 0xFF；
                          諸侯 offset 0／2／6 ← 0xFFFF   ; 0x1241b
```

## 2. 月迴圈（`0x15763`）

```
每一格（游標 es:0x20f4，0..42）：
    DS:0x5b02 == 0（示範模式）而且 0xb01:0x222（有鍵）→ 回 −1，結束示範
    RND(12) …                                     ; TurnTick
    郡 ← 順序表[游標]；這個月還沒輪過（es:[0x24d8+郡×2] == 0xFFFF）→ 0x1746e(郡)
每個郡的回合 0x17471：
    重整守將、無主跳過、重算所屬
    所屬諸侯 offset 0 == 2 → 分派器 0x17504
    否則（== 1）→ 主命令提示，由**這個郡的主人**那一位玩家下一道令
游標到 43 → 示範模式時多一步 0x1e1fc → 月底結算 → 開月 → 接著跑
```

所以多人是**照這個月的郡順序輪**：輪到誰的郡就是那一位玩家下令，沒有「一個玩家
下完再換下一位」這回事。電腦諸侯的郡照常在順序裡插進來。

## 3. remake

| 層 | 做法 |
|---|---|
| `internal/ui` | `DrawLordPick` 的提示是空字串時提示框內部留底圖（人數那一問還沒經過訊息常式）；`DrawLordPickAsk` 在 (424,340) 寫洋紅 13。|
| `internal/game` | `State.Players`（依玩家序號排的勢力）；`IsHuman(勢力)`。規則裡原本問「是不是玩家」的地方全部改問 `IsHuman`（`playerCommand`、`noPlayerIn`、守方整編排序、主戰場的 `Computer[side]`）。開局寫諸侯 offset 0：玩家 1、其餘在用的 2；沒人選的新君主欄照 §1 清掉（`clearFillerSlots` 帶玩家集合）。`State.Player` 留作「第一位玩家」，給只有一位玩家時的舊呼叫端。|
| `internal/save` | 存玩家序列；讀舊進度（只有 `player`）時當一位玩家。匯入原版存檔照諸侯 offset 0 == 1 取全部玩家。|
| `internal/session` | `Players`；新增 `AdvanceToHuman()`：從游標往下跑，遇到「玩家的郡、這個月還沒下令、不是自治」就停下回傳那個郡；游標跑完就月底結算、開月、繼續。示範模式（0 人）每呼叫一次最多跑一個郡，讓畫面能換、能按鍵結束。原本的 `EndMonth()` 保留（跳過玩家的郡、跑到月底，給對拍與測試用）。|
| `internal/menu` | 年代 → **玩家人數** → 逐位選君主（`第N位,請選擇`、翻頁、已選的跳過、肖像印序號）→ 設難度 → 新君主分配（被選走的新君主欄才分配）。0 人：印「電腦自動示範模式」、等鍵、再設難度。|
| `internal/game` 的鏡頭 | 0 人局月底先跑 `RunDemoCamera`（`0x1e1fc`，`docs/re/06` §9）再結算：換被看的郡與人、偶數月排郡資料面板（`Bubble.Panel`）、奇數月排人物卡。|
| `cmd/san1` | 主畫面停在 `AdvanceToHuman` 回傳的郡：狀態列換成那個郡主人的君主、只能對那個郡下令（查看類不限）；下完一道令或按 Enter（休息）就結束那個郡的回合、往下跑。示範模式每幀推一格，按任意鍵回主選單。|

**remake 差異**：原版的主命令一次只給那個郡一道令，remake 沿用；原版「其他 → 戰役」
開關在示範模式被關掉，remake 對應 `Options.SkipAIWar`。
