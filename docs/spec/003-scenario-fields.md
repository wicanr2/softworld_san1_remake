# 003：劇本記錄的欄位

狀態：`READY`（只涵蓋 §2 那四個欄位）

`docs/spec/002` 把三張表當成不透明的位元組，只解姓名。這一份加上
**四個已交叉驗證的欄位**。其餘欄位仍然不透明。

## 1. 執行期與磁碟同版面（`L1`）

原版把三張表**原封不動連續載進記憶體**，順序與容器裡相同：

```
0x399B0  BASEMAS  16 × 72  = 1,152
0x39E30  BASESTA  43 × 176 = 7,568
0x3BBC0  BASEGEN  350 × 30 = 10,500
```

（`org_game/三國演義` base 版、劇本 `001`、劉備、難度 5，走到主畫面時量的。
位址會隨配置器狀態變，**形狀不會**。）

三段首尾相接，總長 19,220 bytes。磁碟位元組與記憶體位元組在載入當下
完全相同（`BASEGEN` 到主畫面時已有 182 bytes 被改動，那是回合狀態）。

**所以磁碟版面就是執行期版面**，兩邊可以互相驗證。

## 2. 已驗證的欄位

### `BASEMAS` offset 2（`uint16` LE）＝ 君主的人物索引

16 個槽位的值是 `0, 13, 15, 16, 22, 14, 12, 34, …`，查 `BASEGEN` 得到
劉備／曹操／孫堅／袁紹／袁術／董卓——**與原版君主選擇畫面上的順序與人選
逐一相同**。槽位 14、15 指向 `346`／`347`，那是姓名為全形標點的填充筆
（`docs/formats/03` §4），所以實際可用的勢力是 14 個。

### `BASESTA` offset 30（`byte`）＝ 所屬勢力，`0xFF` ＝ 無主

42 個郡裡 24 個有值、18 個是 `0xFF`。有值的全落在 `0`–`13`，
正好是 14 個實際勢力。同一批 18 個郡在 offset 33 也是 `0xFF`。

得到的領地分佈與原版畫面一致（有色 vs 白色），也與史實一致：

```
劉備 齊郡          曹操 陳留          孫堅 長沙
袁紹 渤海·鄴郡      袁術 潁川·南陽      董卓 上黨·弘農·洛陽·京兆
劉焉 成都·巴郡·永昌  馬騰 武威          劉表 襄陽·南郡·宜都
陶謙 琅邪·下邳      公孫瓚 涿郡        劉繇 建業
王朗 吳郡          孔融 北海
```

原版主畫面的狀態列寫「劉備 主公，請對(8)」，而 8 正是齊郡。

### `BASEGEN` offset 18（`byte`）＝ 勢力，`0xFF` ＝ 在野

### `BASEGEN` offset 19（`byte`）＝ 所在郡

兩個一起驗：346 位人物裡 108 位有勢力、238 位在野。
**108 位的所在郡全部歸屬於自己的勢力，零例外。**
兩張表由不同欄位獨立編碼同一件事，而它們完全對得上。

劉備陣營的前三位是劉備、關羽、張飛。

## 3. 還沒定案的（`L2`，不要實作）

證據強度不足以寫進 `internal/`。**猜出來的版面會自洽、會通過型別檢查、
不會報錯**（`CLAUDE.md` §7 第 18 條）。

| 位置 | 假設 | 支持的證據 | 缺什麼 |
|---|---|---|---|
| `GEN` off 7（byte）| 年齡 | 劉備 29、曹操 35、孫堅 34——與生年推算的 189 年歲數相符 | 只驗了三個人，而且是我挑的 |
| `GEN` off 8/9/10/11（byte）| 四個 0–100 屬性 | 值域 9–100；主程式字串表列的標籤順序是 体能／謀略／戰力／魅力 | **哪一個是哪一個沒有證據**。劉備 off11 ＝ 100、董卓 off11 ＝ 24 讓「off11 ＝ 魅力」看起來對，但那是合理性不是證據 |
| `GEN` off 13（byte，1–42）| 出身郡 | 劉備 涿郡、孫堅 吳郡 | 同上，只驗了兩個 |
| `GEN` off 16（byte）| 忠誠 | 君主與關羽、張飛都是 100 | 同上 |
| `GEN` off 22–23（`uint16`）| 兵士數 | 董卓 5000、袁術 1400、曹操 800、劉備 100；字串表有 `兵士數 %4d` | 沒有與畫面對照過 |
| `GEN` off 21（byte，0–6）| 兵種 | 值域小、字串表有「兵種」 | 沒有對照 |
| `MAS` off 4（`uint16`）| 曾假設是「擁有郡數」| —— | **已推翻**：總和 21，實際擁有 24 |
| `GEN` off 14（byte）| 曾假設是「君主／親族的人物索引」| —— | **已推翻**：346 筆裡 176 筆指向自己，曹純指向孫乾 |

### 怎麼定案

原版主畫面有「0 狀態」與「1 查看」兩個命令會把人物屬性印出來。
在按下它們的前後對 `BASEGEN` 那一段設讀取監看，就知道畫某個標籤時
讀了哪一個 offset。**那是版面的直接證據，不是合理性。**

## 4. 驗收

`internal/state` 解出的勢力領地表與上面 §2 的十四行相同；
`internal/parity` 的 `-tags orig` 測試釘住這件事。
