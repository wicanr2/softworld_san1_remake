| 項目 | 尺寸 | 是什麼 |

| `UPR00`–`UPR21` | 各 ?×24，22 條 | **字幕**，一張長圖切成 24 列一條 |

## 2. 遮罩對的是 `REC10`（`L1`）

把遮罩的 1 當天空、0 當山，與圖裡「這一格是不是天空色（11）」逐點比：

| 圖 | 位移 | 吻合 |
|---|---|---|
| `REC10` | **y ＝ 54** | **99.39%** |
| `REC11`（正對照）| 同上 | 51.31% |

所以 `ENDO4.MSK` 是 `REC10` 的**天空與山的分界**，對齊位置是往下 54 列。
正對照要一起跑——不然「吻合」這個數字分不出兩張圖。

## 3. remake 這一側

### R1 版面

背景圖 640×336 畫在 `y = 36`：畫面 408 高，上下各留 36——**那與主畫面
上下花邊的高度相同**（`assets.MapBorderBottomY` ＝ 372，408 − 372 ＝ 36），
所以不是隨便取的中間值（`L2`）。

字幕水平置中，由下往上捲，緊貼（步距 24）。

### R2 字幕從山後面升起

每一個字幕像素只有落在**天空那一側**才畫得出來（`Credits.SkyAt`）：

```
y < 54          → 天空（含負的 y：捲到畫面頂端時還在天空裡）
54 ≤ y < 205    → 看遮罩
y ≥ 205         → 不是天空
```

色號 0 當透明（字條是黑底彩字）。

### R3 什麼時候播（`L3`，**remake 的推測**）

統一天下之後：先定格在朝堂圖，按鍵之後字幕上捲，再按一次跳過。
一局只播一次。

**原版什麼時候播沒解**——那一段跑在 `DATA0.GRP`／`DATA4.GRP` 兩支還沒
反組譯的 overlay。`ENDO` 這個名字（ENDing）與朝堂圖的內容都指向結局，
但那是推測不是證據。

### R4 速度是 remake 自己定的

2 像素／幀，60 fps 下走完約 15 秒。原版的速度由那支 overlay 的迴圈決定，
沒量到。

### R5 讀不到素材就不播

**沒有製作群不該擋著結局**：讀不到就記一筆到 stderr，直接跳過。

## 4. 驗收

| 項 | 怎麼驗 |
|---|---|
| 素材的尺寸與條數 | `internal/assets` 的 `TestCreditsAssetsMatchTheOriginal` |
| 遮罩對的是 `REC10`（含正對照）| 同上，99.39% vs 51.31% |
| 遮罩的三段界外行為 | `TestCreditsSkyAtOutsideTheMask` |
| 字幕只在天空側畫得出來 | `internal/ui` 的 `TestDrawCreditsRespectsTheMask` |
| 緊貼沒有行距 | `TestCreditsLength` |
| 畫面上真的有 | `cmd/san1dump -screen credits -months <捲動量> -png` |
