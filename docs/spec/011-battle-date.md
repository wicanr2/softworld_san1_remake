# 011：主戰場下方花邊上的年月

狀態：`READY`

範圍：主戰場（`MAINMAP8` 那條下方花邊）上寫的一行年月與季節。
主畫面左側直排寫的是同一個東西，版面不同。

證據等級：`L1`（量在原版基準畫面 `workplace/shots/bf/orig-battle.png`
上，**只有一個樣本**：「建安二年九月秋」）。
版本：`[base]`。

## 1. 版面（`L1`）

**十個格子**，每格 24 寬，左緣 `128 + 40i`（i ＝ 0..9）；
字的上緣 `y = 378`、高 23。

| 格 | 內容 | 樣本 |
|---|---|---|
| 0–1 | 年號兩字 | 建 安 |
| 2–3 | 年數，**靠右** | （空）二 |
| 4 | **一直是空的** | |
| 5 | 「年」 | 年 |
| 6–7 | 月份，**靠右** | （空）九 |
| 8 | 「月」 | 月 |
| 9 | 季節 | 秋 |

**靠右是從樣本推的**：個位數的「二」落在格 3 而不是格 2。

季節照農曆分界（正月就是春），與主畫面直排同一條規則
（`docs/mechanics/50-events` §1）。

## 2. 字的顏色是兩色棋盤（`L1`）

`(x+y)` **奇數用色號 7（灰）、偶數用色號 2（綠）**。

判準是相位不是比例：量到灰 538 點、綠 502 點，而 (+1,0) 有 388、
(0,+1) 有 329、**右下 (+1,+1) 只有 4 點**。「主色 ＋ 右下陰影」會讓
(+1,+1) 最多——所以那不是陰影，是棋盤。

> 這一條原本被記成「網點的機制沒解，可能與 `8x8AND*`／`.MSK` 遮罩是
> 同一件事」。量了相位就知道不必扯到遮罩：一條 `(x+y)%2` 就夠了。

## 3. remake 這一側

### R1 `Canvas.DrawRuneBoxDitherPx`

把一個字**按比例**縮放進 `w×h` 的方框（16→24 是 1.5 倍，整數倍放不進去），
前景依 `(x+y)` 選兩個色。缺字記一筆 `Missing`，與其他畫字的路徑一致。

### R2 字形是 remake 自己的（**remake 差異**）

原版那一行是 24×23，remake 的字模是 16×16 按比例放大——**筆畫不會逐點
相同**（`CLAUDE.md` §3.3：remake 自建字庫，不內嵌任何原版字模）。
對得上的是**版面與網點**，不是字形。

### R3 年數超過兩個中文字時退回半形數字（**沒有樣本**）

那兩格只放得下兩個字，而「二十一」是三個。取最後兩個字會變成「十一」
——一個讀得通而錯的年份，所以改成半形數字（`2` `1`）。

**原版怎麼處理沒有樣本**：手上只有建安二年那一張。要補樣本得讓原版
走到建安二十一年之後再開一場戰役。

### R4 西曆那條路也沒有樣本

原版切成西曆時這一行寫什麼沒量過。remake 照同一個版面排阿拉伯數字
（年放前四格）。
