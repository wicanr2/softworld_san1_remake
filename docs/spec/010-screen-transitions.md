範圍：計謀得手之後那一段四選一的拉幕（`0x32e40`）。其他動畫的清單在
`docs/re/10` §4。

版本：`[base]`。

## 1. 已經讀出來的（`L0`）

```
lcall 05C4:051C            ; 前置
RND(4) → 四選一
  0、1 → i = 3; i < 0x60; i += 4    （24 步）
  2、3 → i = 0; i < 0xaf; i += 8    （22 步）
每一步：lcall es:[0x3efc] 搬一塊 → speak(0, 10)
```

- 區域是 **96 × 176**（`0x5f+1` × `0xaf+1`），原點由兩個參數給。
- **每一步一聲音效**（`docs/spec/008` §4）。
- `RND(4)` 那一次抽樣 remake 已經照擲（`internal/game/plot.go` 的
  `g.Roll(4, …)`），月度對拍靠它才對得上。

## 2. 缺什麼

| 缺口 | 為什麼擋著 |
|---|---|
| `es:[0x3efc]` 是什麼 | 是複製、填色還是帶遮罩的搬運沒讀出來。不知道就畫不出來 |
| 四個分支的方向 | 參數形狀看起來是兩橫兩縱，但沒有逐格畫面佐證 |
| 什麼時候還會轉場 | 只驗過「計謀得手」一條；失敗會不會也轉場沒有樣本（`docs/mechanics/70-ai` §2.13.7）|

補法：`internal/parity` 加一支攔 `0x32e40`、每步存一張 PNG 的測試，
與 `TestZZMonthAnimationFrames` 同一個做法。

1. 四個分支各有一串逐步 PNG，方向確定。
2. `es:[0x3efc]` 的語意讀出來（或用逐步 PNG 反推到能逐點重現）。
3. remake 這一側有可以掛的訊息面板幾何（`docs/spec/006`）。
